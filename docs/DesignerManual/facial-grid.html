グリッドタブ

最終更新日: 2026-10-03

どの角度に補正ポーズを作るかを決め、ベイクして、プレビューで確かめる場所です。

格子の見方

横が Yaw（左右の角度。中央が正面）、縦が Pitch（上下の角度。上がふかん、下があおり、真ん中が水平）です。左端は −（カメラがキャラクターの右）、右端は +（カメラがキャラクターの左）です。

見た目意味
緑キー（自分で作ったポーズ）
水色自動生成（キーから自動で作ったポーズ）
灰色空（まだ何も無い）
黄色の破線の枠未ベイク（まだ焼いていない）
桃色の実線の枠変更あり（ベイクしたあとにポーズを変えた）
橙色の太い枠選んでいる点
赤い点今の Maya のカメラの角度。カメラを回すと動きます。格子の外に出ると端に寄り、「範囲外」と出ます

格子の下に「キー 3 / 生成 0 / 空 12 / 未ベイク 0」のような集計が出ます。点にカーソルを合わせると、その点の角度と状態が出ます。

点を選ぶ

点をクリックすると、その点が選ばれ、シーンにその点のポーズが当たります。カメラも動かす にチェックがあれば、Maya のカメラもその角度へ動き、顔を見ます。チェックを外すと、ポーズだけを当てます。選ぶと自動で編集が始まり、ポーズタブでその点を編集できます。

保存していないポーズの編集があるときに別の点を選ぶと、保存 / 破棄 / キャンセルを聞かれます。

点の操作

ボタンはたらき
自動生成キーから残りの点を埋めます。キーは変わりません。すでにある自動生成の点は作り直されます（確認が出ます）。全レイヤーにチェックすると全レイヤー、外すと今のレイヤーだけ。左右反転した点も作るので、右側だけキーを作れば左側が埋まります
キー解除選んでいる点のキーを外します。ポーズは残り、自動生成の点になります
クリア選んでいる点を空にします。焼いた FC_ のシェイプもシーンから消えます
レイヤーをクリア今のレイヤーの点を全部消します（確認が出ます）

他のデータからコピー

別のキャラクターで作った補正を、出発点として持ってきたいときに使います。他のデータからコピー… を押し、コピー元のデータ（.fcpose.json）を選びます。

項目意味
全レイヤー名前が同じレイヤー同士でコピーします（このデータに無いレイヤーは作ります）。外すと、今のレイヤーだけ
作業セットだけこのデータの作業セットのシェイプ・ボーンだけをコピーします（作業セットが空なら全部）
キーだけ（初期はオン）コピー元のキー（緑の点）だけを使います。外すと、コピー元の自動生成の点も使います
  • 格子の大きさが違っても大丈夫です。角度で補間し直して、このデータの格子に合わせます
  • コピーした点は、自動生成の点（水色）になります。このデータにあったキーも上書きされるので、注意してください
  • Maya の Ctrl+Z で戻せます
  • コピーしたあとは、ベイク（変更のある点）を押してベイクします。キーにして残したい点は、点を選んでポーズタブで保存します

右クリック

点を右クリックすると、キー解除 / クリア / この点だけベイク / ポーズをコピー / 貼り付け / 左右反転して貼り付け / カメラをこの点へ が選べます。右側で作ったポーズを左側へ「左右反転して貼り付け」すると手早く作れます。

サムネイル（各点の小さな顔の画像）

サムネイルを表示（初期はオフ）をオンにすると、ポーズのある点のマスに、その角度から見た顔の小さな画像が敷かれます。

  • 画像は サムネイルを作り直す で作ります。一時的なカメラで撮るので、今のカメラ・選択・編集中の値は動きません（数秒かかります）
  • ポーズを変えた点の古い画像は表示されません。作り直すと更新されます
  • 画像はパソコンの一時フォルダに置かれ、プロジェクトには入りません
実際の Maya での撮影はまだ確認中です。画像が出ないときは、ビューポートが表示されている状態で作り直してください。

ベイク

点のポーズを、顔メッシュの FC_ で始まるシェイプに焼き込みます。元からあるシェイプには触りません。Maya の Ctrl+Z を 1 回押すと、ベイク前に戻ります。

ボタン焼く範囲
ベイク（変更のある点）未ベイク・ベイク後に変更した・シェイプが消えた点だけ。速いので普段はこれ
ベイク（全部）全レイヤー・全部の点
ベイク（この点）選んでいる点だけ
ベイク（このレイヤー）今のレイヤーの点だけ
  • 結果（作った数・置き換えた数・頂点数・時間など）が下の欄に出ます
  • Neutral の点を焼くと、感情レイヤーの同じ位置の点も一緒に焼き直されます（感情は Neutral との差を持つため）
  • 編集中でまだ保存していないポーズは焼かれません。先にポーズタブで保存してください

誇張（重みが 1 を超えるポーズ）

ポーズでシェイプの重みを 1 より大きくすると、ベイクのときに、1 を超えた分が別の誇張用シェイプ（FC_…_Ex）に分けて焼かれます。通常のシェイプには 1 までの分が入ります。

  • Maya のシーンでは、1 を超えた分は元のシェイプをそのまま直線で延ばした形になります（シェイプタブの誇張形 <名前>_Ex には切り替わりません）。焼かれるのも、この見えている形です
  • 誇張できるのは、動かせる範囲の上限を 1 より上げたシェイプです（シェイプタブの「誇張形 _Ex を作る」で 0〜2 に広がります）
  • プレビューの「誇張」スライダー（0〜1）で効き具合を確かめます。0 = 誇張なし（重みを 1 までに収めた形）、1 = 作った通り
  • Neutral の点に誇張があると、感情レイヤーの同じ位置の点にも誇張用シェイプができます（Neutral の誇張と合わせて、感情のポーズが作った通りになるようにするため）
  • 重みを 1 以下に戻して焼き直すと、古い誇張用シェイプは消えます
  • 誇張の強さは、Unity では Runner の調整値か Timeline のクリップで変えます（.fctrack には入りません）

プレビュー

ベイクした補正が、カメラの角度に合わせて動く様子を Maya で確かめます。グリッドタブの下の「プレビュー」の箱です。

項目はたらき
プレビューを作る（作ったあとは「作り直す」）ベイク済みの FC_ シェイプを、カメラの角度に合わせて自動で動かす仕掛けを作ります。カメラを回すと補正が追従します
消す仕掛けを消します。FC_ の重みは 0 に戻ります
補正あり / 補正なし切り替えボタン。補正の前後を見比べられます（補正なし = 元の形）
カメラ補正を計算するカメラ。「今のビューのカメラ」か、モデルパネルのカメラ
強さ補正全体の強さ（0 = 補正なし、1 = そのまま）
誇張誇張用シェイプ（FC_…_Ex）の効き具合（0〜1）。誇張用シェイプが無いときは動かせません。→ 誇張
感情 ○○感情レイヤーごとの重み（0〜1）。重みを上げると、その感情の補正が上乗せされます
角度を手動で決めるカメラの代わりに、下の Yaw / Pitch の数値で補正を計算します。決め打ちで見たいときに使います
キーに焼く…開始・終了フレームとステップを決めて、補正の動きを FC_ の重みのキーとして打ちます。焼いたあとはプレビューの仕掛けが外れます（キーだけで同じ補正になります）。「焼いたあと、プレビュー用ノードを消す」のチェックで選べます。Ctrl+Z 1 回で戻せます

表示の意味

表示意味と対処
格子やベイクが変わりました。作り直してくださいプレビューを作ったあとで、格子やベイクが変わりました。「作り直す」を押すと最新になります。ベイクや格子の変更のあとは自動で作り直されますが、編集中は保留されるのでこの表示が出ます
編集中は補正が止まっています（シーンが基準姿勢のため）編集がオンの間は補正が掛かりません。編集をオフにすると再開します
（キーあり）強さや感情にキーが打ってあるため、スライダーでは動かせません
プレビューで「補正あり」と「補正なし」を切り替えながらカメラを回すと、崩れが直っているか分かりやすくなります。
