出力タブ

最終更新日: 2026-10-22

Unity（MS2026 / D-Drive）に渡すファイルを書き出します。モデルと、動き 1 つごとのファイルに分けて出します（D-Drive の決まり: モデルとアニメーションは別のファイル）。

ファイル中身
SK_<ModelId>.fbxメッシュ + スキン + スケルトン（骨）。アニメーションは入りません。バインドポーズ（基本の姿勢）で書きます
A_<ModelId>_<動作>.fbx（クリップごとに 1 つ）骨だけ（メッシュなし）。クリップの範囲を 1 フレームごとに焼き込み（ベイク）、先頭が 0 フレーム。コントローラやコンストレイントは入りません。1 ファイルに 1 つの動き
humanoid.json / animset.jsonモデルと同じフォルダに書きます。Unity 側で人型の設定（Avatar）やアニメーションの設定を作るときの元データ
Model@Anim.fbx のような「@ で分ける」書き方は使いません（D-Drive の規則）。D-Drive は、アニメーションのファイルの最初の動きを、ファイル名で取り込みます。

出せないとき

出力ボタンが灰色で、赤い文字で理由が出ているときは、命名の❌があります（フレームレートが 30 fps でない、クリップ名に @ がある、スケルトンのルートが見つからない、など）。命名タブで直してから、「命名を確認」を押してください。出力ボタンを押したときにも確認します。

出し方

  1. 出力先を選ぶ — 既定は、プロジェクトの build/unity/<ModelId>/（アニメは中の anim/）。MS2026 / D-Drive の SourceAssets は、「MS2026 のパス…」「D-Drive のパス…」ボタンで Unity プロジェクトのフォルダ（Assets の 1 つ上）を選ぶと使えます（選んでいないと灰色で、理由が出ます）。「フォルダを開く」で確認できます
  2. モデルを出力 — 出力するメッシュは animset に入っています。空のときは、スケルトンにスキンされたメッシュを自動で選びます。「スキンされたメッシュを animset に設定」で入れることもできます（そのあと上の「保存」）
  3. アニメーション — 出したいクリップにチェックを入れて「チェックしたクリップを出力」
  • 書き出しは別のプロセスで行うので、Maya はそのまま操作できます。開いているシーンは変更されません。進み具合は画面の中の進捗バーと、下のログに出ます（出力したファイルの名前・サイズ・警告）
  • ウィンドウを閉じると、実行中の書き出しは止まります
  • 同じ名前のファイルは上書きされます

変更のあるクリップだけ

「変更のあるクリップだけ」にチェックが入っていると（既定）、前回の出力からクリップの範囲内のアニメーションや属性が変わっていないクリップは飛ばします（ログに「変更なしのため飛ばしました」と出ます）。出力先のファイルを消したときや、出力先を変えたときは、全部が対象になります。全部を出し直したいときはチェックを外してください。記録は anim/<ModelId>/.export-state.json に残ります（Git には入れません）。

変更を調べるのは、キー（アニメーションのカーブ）と、クリップの属性です。アニメーションレイヤーの重みや、コンストレイントの設定を変えただけのときは「変更なし」に見えます。迷ったら、チェックを外して全部出してください。

ルートモーション

クリップの「ルートモーション」が none（既定）のとき、腰（Hips）の前後・左右の移動（X と Z）は、クリップの最初の位置に固定されます。その場で動く待機や走りのアニメーションに使います。bake のときは、動きをそのまま出します。上下（Y）は固定しません。

ショット

仮の決め

  • 出力先の既定は build/ です。MS2026 の Assets/_Project/DDrive/SourceAssets/ に直接出すかどうかは確認中です
  • Unity 側での Avatar や AnimatorController、AnimData の自動作成は、このツールではまだ行いません（humanoid.json / animset.json を元に、あとで作る予定です）
  • FBX のテイク名は Maya の既定（Take 001）です。D-Drive は最初の動きをファイル名で取り込むので、影響しません
