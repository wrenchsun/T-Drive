アニメーション作業台とは

最終更新日: 2026-10-22

ゲーム（Unity）に入れるキャラクターのアニメーションを、Maya の中で整える・確かめる・書き出すための道具です。MS2026 のキャラクター「MisotenChara」を対象にしています。

  • 名前を揃える — MS2026 の名前の決まりに合っているかを調べて、直す案を出します
  • クリップを作る — 「待機」「走る」「ジャンプ」など、動きの範囲に名前を付けて並べます
  • つなぎ方を確かめる — 待機から走りへ切り替わるときのなめらかさを、ゲームと同じ秒数で見ます
  • Unity 用に分けて出す — モデルと、動き 1 つごとのファイルに分けて書き出します
  • ショット（カットシーン）を作る — カメラとキャラクターの動きを並べて、Unity のカットシーン用に書き出します
DirectX 11 でなくても使えます。Toon のプレビューは DirectX 11 が必要ですが、アニメーション作業台は Maya の標準のアニメーション機能だけで動きます。Toon 表示がオフ（元のマテリアル）でも使えます。

画面

メニュー Tools › T-Drive › Animation…（または エディタを開いて 1 段目の「Animation」タブ）を開きます。上に ModelId と animset の表示、その下に 5 つのタブがあります。

タブ役割
命名名前の決まりの検査と直し、シーンの設定（フレームレートなど）、掃除、Humanoid の対応表
クリップ動きの範囲（クリップ）の一覧と再生、属性、イベント
ブレンドクリップからクリップへのつなぎ（ブレンド）と、状態の切り替わり（遷移）の確認
ショットカメラとキャラクターの動きを並べる（カットシーン 1 つ分）
出力Unity 用の書き出し（モデル・アニメーション・ショット）

はじめかた

  1. Maya にキャラクターのシーンを開きます
  2. Animation タブの上の欄に ModelId を入れて「新規」を押します。ModelId は英数字の「大文字で始まる」名前です（例: MisotenChara）。その ModelId の animset が既にあるときは「既存を開く」か「新規にして上書きする」かを聞かれます（既定は「既存を開く」。上書きすると中のクリップの記録が失われます）。未保存の変更があるときの「新規」「開く…」も確認が出ます
  3. リグを参照して読み込んだシーン（ネームスペースがある）では、その下の「リグのネームスペース」欄にネームスペースを入れます（例: MisotenChara）。ネームスペースの無いシーンは空のままです
  4. 「保存」を押すと、プロジェクトの anim/<ModelId>/animset.json ができます。シーンを保存したときも自動で保存され（シーンにはその場所が一緒に記録されます）、シーンを開き直すと自動で読み込まれます。新しいシーンにしたときは、前のシーンの animset は閉じます（未保存の変更は破棄され、その旨が出ます）
ModelId の MisotenChara は仮の決めです（ファイル名から付けました）。MS2026 側で別の名前に決まったら、ここを変えれば他は追従します。

用語

用語意味
ModelIdキャラクターを表す名前。ファイル名（SK_<ModelId>.fbx）やカットシーンの名前に使います
animset1 キャラクター分のアニメーションの設定ファイル（animset.json）。クリップの一覧・つなぎ方などを持つ正本です
クリップ動きの範囲（開始〜終了フレーム）に付けた名前。Unity では 1 つのアニメーションになります
ブレンド2 つのクリップをなめらかにつなぐこと。時間で線形に混ぜます（Unity と同じ）
遷移待機 → 走り のように、状態が切り替わること
ショットカットシーン 1 つ分。カメラとキャラクターの動きの組

一周の手順（MisotenChara で通しで試す）

キャラクターのリグ MisotenChara_Rig.ma を開いた状態から、Unity に渡すファイルを作るまでの流れです。どこでも止まったら、画面の赤い文字や黄色の注意を読んでください。

  1. animset を作る — 上の欄に ModelId MisotenChara を入れて「新規」（このリグにネームスペースが付いているときは、「リグのネームスペース」欄も）
  2. 命名 — 「検査」→ フレームレート（24 → 30 fps）を「直す」→ 名前の提案にチェックを入れて「適用」→ Humanoid を「ジョイントから推定」して「保存」
  3. クリップ — タイムスライダーの範囲を合わせて、Idle・Run・Jump など動きごとに「追加」→ ▶ 再生で確認 →「保存」
  4. ブレンド — 遷移列（Idle → Run → Jump）か、MS2026 の状態図（Speed / ActionState）で合成して再生。確認できたら「合成を外す」
  5. 出力 — 「モデルを出力」と「チェックしたクリップを出力」→ build/unity/MisotenChara/ に SK_MisotenChara.fbx と anim/A_MisotenChara_….fbx
  6. ショット — 新規ショット → カメラの区間 → キャラクターを足してクリップ列（ブレンドタブの「この列をショットへ」）→ イベント →「ショットを反映」→ ▶ シーケンサー再生 →「合成を外す」→「保存」
  7. 出力（ショット） — 「ショットを出力」→ build/cutscene/<カテゴリ>/ に <Shot>.fbx と <Shot>__MisotenChara.fbx
Maya の OpenGL（DirectX 11 でない）の画面でも、この流れはすべて動きます。

今できること

機能状態
animset の新規・開く・保存、シーンとの紐付け、元に戻す / やり直し（Ctrl+Z）使える
命名の検査と直し（メッシュ・マテリアル・クリップ・テクスチャ）・シーン設定（30 fps / cm / Y-up）・掃除候補・Humanoid 対応表使える（命名）
クリップ（範囲から追加・一覧・検索・ループ再生・属性・イベント・サムネイル）使える（クリップ。サムネイルの実機撮影は確認中）
ブレンド（遷移列を並べて合成・再生）・遷移（MS2026 の状態図を Speed / ActionState で動かす）・上半身レイヤー使える（ブレンド。見た目は確認中）
Unity 用の分割出力（モデル SK_ と、クリップごとの A_ ファイル・変更のあるクリップだけ・出力先の選択）使える（出力。Unity での読み込みは確認中）
ショットの作成（カメラの区間・キャラクターのクリップ列・イベント・シーケンサー再生）使える（ショット）
ショットの出力（<Shot>.fbx と <Shot>__<ModelId>.fbx）使える（出力。D-Drive での取り込みは確認中）
この道具の画面写真は、実機で撮ったものを順次足します（準備中）。
