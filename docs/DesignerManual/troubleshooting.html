困ったとき

最終更新日: 2026-10-03

症状対処
Toon 表示にならない（白っぽい・つるっとした表示のまま）
  1. ビューポートで 6 を押してテクスチャ表示にする
  2. エディタ上部にオレンジ色の警告が出ていないか確認。「VP2 レンダリングエンジン」が出ていれば DirectX 11 の設定をして Maya を再起動
  3. エディタの「表示」が Toon になっているか確認
エディタ上部にオレンジ色の警告（Unity とのパリティ）が出る ゲームと同じ見た目にするための設定がずれています。表示されている項目を確認してください。色の設定（カラーマネジメント）は、Look を開き直すと自動で直ります
色がくすんで見える・影が変 ツールが古い可能性があります。T-Drive › ツールをリロード を実行してください
髪の内側に暗い帯が見える 片面ポリゴンの裏側から線が見えています（ゲームでも同じ）。Unity との見た目の一致 を参照
スムーズ法線を焼くと「形状のヒストリがあるメッシュには焼けません」と出る そのメッシュに作成時の履歴（ベベルやスムーズなど）が残っていて、そのままだと焼いた値があとで消えてしまいます。メッシュを選んで Edit › Delete by Type › Non-Deformer History（デフォーマー以外のヒストリを削除）をしてから、もう一度焼いてください（スキンは消えません）
Ctrl+Z で値が戻らない エディタ（どのタブでも）をクリックしてから Ctrl+Z を押してください。ビューポートにカーソルがあると Maya 自身の Undo になり、Look の値は戻りません。エディタのルックタブにある 元に戻す ボタンでも戻せます
同じキャラクターを複製・2 体読み込むと Toon 表示が切り替わらなかった 2026-09-28 に修正済み（同じ名前のメッシュがあると止まっていた）。T-Drive › ツールをリロード で最新にしてください
「未保存の変更があります」と出る Look を保存していない変更があります。必要なら 保存、不要なら破棄して続けます
Maya が固まった しばらく待っても戻らない場合は、タスクマネージャーで Maya を終了して再起動してください。Look（looks/…/look.json）は保存した時点の内容が残っています。症状と直前の操作を開発者に伝えてください
テクスチャの欄が赤い そのファイルが見つかりません。プロジェクトフォルダの中にあるか確認し、「…」で選び直してください（ベースマップは ↺ で元マテリアルのものに戻せます）
描き直したテクスチャが反映されない ルックタブ上部の テクスチャを読み込み直す を押してください
リム・接地影などの欄が見当たらない その機能がオフです。機能タブでオンにしてください（オフの機能の欄は隠れます）
インナーライン・外側輪郭が出ない
  1. 機能タブでその機能がオンか確認
  2. キャラクタータブで 使う にチェック。インナーラインは 線を出す部位 にもチェック
  3. エディタの「表示」が Toon か確認（元の見た目では線は出ません）
  4. 半透明の部位には線は出ません（ゲームでも同じ）
線を使っていると輪郭がギザギザになる 画面上の線を使っている間は、ビューポートのアンチエイリアスが効きません（ゲームと同じ条件で比べるため）。線を使わないときは元に戻ります
足元の影の板が選べない・動かせない 接地影のプレビュー用の板（tdContactShadow）です。誤って動かさないよう選べないようにしてあります。ゲームにもモデルの書き出しにも入りません。キャラクタータブで接地影の 使う を外すと消えます
インストーラーで「git が見つかりません」「取得できませんでした」 Git for Windows を入れる / GitHub の wrenchsun/T-Drive を見る権限があるか担当者に確認（はじめに）
更新がうまくいかない 更新のしかた の「うまくいかないとき」を参照
Look が見つからない / 保存先が違う エディタ上部の「プロジェクト」を確認。T-Drive › プロジェクトを選ぶ… で正しいフォルダを選んでください
エディタの上部に赤い「エラー: …」が出る ツールの中で問題が起きました（ツールの不具合です）。表示されている内容と、直前に行った操作を報告してください。詳しい内容はスクリプトエディタ（Windows › General Editors › Script Editor）に出ています。× で表示を消せます
外側輪郭・インナーラインを触っていたら Maya が落ちた（2026-09-28） 「ツールをリロード」の後に画面上の線を使うと落ちる不具合でした。修正済みです。Maya を再起動し、Look を開き直してください（保存していない変更は失われています）
リロードしたら未保存の変更が消えた（2026-09-28 より前） 以前のツールでは、ツールをリロードすると保存していない変更が消えていました。修正済みです（今はそのまま残ります）
「T-Drive」メニューが無い（v0.4.0 までは「T-Drive Toon」という名前でした） ツールの登録（install_maya_module.ps1）をして Maya を再起動してください
FacialController で「編集」をオンにしたら、顔の表情が消えた 編集中は、シーンが基準姿勢（シェイプの重み 0・バインドポーズ）になるためです。故障ではありません。編集をオフにすると元の姿勢に戻ります（はじめに）
プレビューに「格子やベイクが変わりました。作り直してください」と出る プレビューを作ったあとで、格子やベイクが変わりました。グリッドタブのプレビューで作り直すを押してください（グリッド）
ベイクしたのに、カメラを回しても補正が出ない 次を確認してください。(1) プレビューを作っていない → 「プレビューを作る」 (2) ボタンが補正なしになっている → 「補正あり」へ (3) 編集中は補正が止まる → 編集をオフに (4) 強さが 0 になっていないか (5) 点が未ベイク（黄色の破線）のまま（グリッド）
検証に「左右の相手がモデルにありません」と出る そのシェイプの左右の名前が、モデルで合っていません（綴りが左右で違うなど）。左右反転できないだけで、補正は動きます。名前をそろえるか、セットアップタブの反転しないものに入れてください（検証）
シェイプタブで「この角度で彫る」が押せない、または始まらない 次を確認してください。(1) グリッドで点を選んでいない → グリッドタブで点をクリックする（「選択中の点の彫り用シェイプ」と出ていれば押せます） (2) すでに彫っている途中 → 先に彫り終わる (3) その点のポーズが頭のボーンを動かしている → 頭を動かしたポーズでは彫れません。頭は基準姿勢のままにしてください（シェイプ）
ミラーを押したら、頂点が選択されて止まった 左右で位置が合わない頂点があるためです。選択された頂点をビューポートで見て、左右対称になるように直してください。直さずに進めたいときは「それでも続けますか」で続けられます（その頂点は 0 のままになります）。わずかなずれなら、「ミラーの許容誤差」を少し大きくする方法もあります（シェイプ）
土台の表情を当てたら、スライダーの値と見た目が違う 土台の表情は、ポーズの値に足されてシーンに当たるためです（ゲームでも同じ足し算になります）。スライダーはポーズ自身の値で、土台ぶんは横の「+…（土台）」に出ます。合計が動かせる範囲を超えた行は警告の色になります。土台を消したいときは外すを押してください（ポーズ）
Timeline の「Facial Correction」トラックを置いたのに、補正が変わらない (1) トラックがキャラクターに結ばれているか（Animator を結ぶ。D-Drive では Binding の Target を SameAsTrack にするか、トラック名を「<役名>_Facial」に） (2) キャラクターに Facial Correction Runner が付いていて、データが入っているか (3) D-Drive の検証に TD-FACIAL-001〜005 が出ていないか（意味は出力と Unity） (4) クリップの外は通常の補正に戻ります。クリップの範囲内か (5) 感情レイヤー名の綴り（大文字・小文字も区別）。直らなければ状況を開発者に伝えてください（Timeline の実際のカットシーンでの確認は、まだ終わっていません）
Unity で補正が出ない (1) FBX に FC_ で始まるシェイプが入っているか（Maya の出力タブで「FBX に入った FC_*」の数を確認）(2) Runner の状態の「足りないシェイプ」が 0 か (3) Runner の検証のエラー・警告 (4) データ・基準ボーンが設定されているか (5) 補正が弱くなっていないか（全体の強さ・距離フェード）。直らなければ Maya で出し直してください（出力と Unity）
困ったことや分かりにくいところがあったら、開発者に伝えてください。このページに追記します。
