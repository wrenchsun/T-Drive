レイヤー（感情）と検証

最終更新日: 2026-10-04

レイヤー（感情）

表情が変わると、同じ角度でも崩れ方が変わります（笑った顔のあおり、怒った顔の横顔など）。そこで補正をレイヤーに分けます。

  • Neutral は土台です。無表情のときの補正で、常に効いています。名前の変更・削除はできません
  • 感情レイヤー（喜び・怒りなど）は、Neutral との差だけを持ちます。重み（0〜1）を掛けて Neutral の上に上乗せされます。重み 0 なら Neutral だけ、1 なら Neutral にその感情の差が足されます
  • 感情レイヤーは Neutral を含めて最大 16 個です

操作

項目はたらき
一覧行を選ぶと、そのレイヤーが編集の対象になります（グリッド・ポーズタブで編集）。列は 有効 / レイヤー名 / 感情カーブ / 点（キー数・ベイク済み数）。有効を外すと、Unity での評価から外れます。感情カーブはダブルクリックで書き換えられ、Unity で感情の重みを受け取る名前になります
レイヤーを足すプリセット（Anger 怒り / Contempt 軽蔑 / Disgust 嫌悪 / Fear 恐れ / Joy 喜び / Sadness 悲しみ / Surprise 驚き）のボタン、または自由な名前（英数字と _）を入れて「追加」。すでにあるプリセットは押せません。同じシーンに、名前が似たキャラクター ID（例: a と a_b）の別のキャラクターがいるときは、_ 入りのレイヤー名が相手のシェイプ名と重なることがあります（検証タブに警告が出ます。レイヤー名を変えてください）
名前を変える…名前を変えると、焼いた FC_ のシェイプは消え、新しい名前の分は未ベイクになります。ベイクし直してください
削除…レイヤーと、焼いた FC_ のシェイプを消します（確認が出ます）
ポーズをコピー: 元 〜 コピーほかのレイヤーのポーズを、選んだレイヤーへコピーします（叩き台作り）。同じ位置の点は上書きされます

感情レイヤーの作り方

  1. 先に Neutral の点を作ってベイクします
  2. 「レイヤーを足す」で感情（例: Joy）を追加します。編集の対象が Joy になります
  3. グリッドで点を選び、その感情の顔のポーズを作って保存します（Neutral のポーズに対してその感情で必要な補正を足したポーズ）
  4. ベイクします。プレビューの「感情 Joy」を 0 → 1 に動かして、上乗せを確かめます
Neutral のポーズを直したときは、Neutral の点を焼くと感情レイヤーの同じ点も焼き直されます。感情の差は Neutral が変わると変わるためです。

重みの出どころ（選んだレイヤー）

感情レイヤーの重みを、どこから受け取るかを選びます（Neutral にはありません）。

  • 直接（Timeline / 部品の値） — Timeline のクリップや Runner の値から重みを受け取ります（初期値）
  • カメラの距離 — カメラと格子の中心の距離で、自動で決まります。距離が「開始」のとき「から」の重み、「終了」のとき「まで」の重みで、間は直線です。遠景だけデフォルメ用のレイヤーを効かせる、などに使います。Unity でも同じ距離で決まります

Maya のプレビューでは、距離で決まるレイヤーの「感情」スライダーは使えません（「距離で決まる（今 60 cm）」と出ます）。

表情が強いときに補正を弱める

口を大きく開けた顔などで、補正が強く出すぎることがあります。ここでは表情が強いほど補正を弱められます。

  • 弱める強さ — 0 = 弱めない / 1 = 表情が最大のとき補正を 0 にする
  • 強さを測るシェイプ — 表情の強さを測るシェイプ（例: 口の開き）。チェックしたシェイプの最大値で弱めます。何もチェックしなければ、作業セットのシェイプ全部の最大値になります

検証タブ

データとモデルを突き合わせて、問題を一覧にします。検証 ボタンを押したときだけ調べ（自動では調べ直しません）、データもシーンも変えません。最後の検証のあとでデータが変わると、「最後の検証のあとでデータが変わりました」と出ます。

重さの区分

区分意味
エラー構造の問題。基準ボーンが無い・格子が不正・レイヤー 0 が Neutral でない・レイヤー名の重複など。直さないと正しく動きません
警告参照先が無い・大小文字の違い・動かせる範囲の外・ベイク後に変更・孤立した FC_ など。動きますが、意図と違う結果になります
情報未ベイク・空のレイヤー・標準シェイプの不足など。知らせるだけです

一覧はエラー → 警告 → 情報の順です。点の場所がある行は、ダブルクリックでグリッド / ポーズタブがその点へ移ります。

ボタン

ボタンはたらき
検証調べ直します
候補で一括改名「改名の候補」で選んだ名前に、データの中の名前をまとめて書き換えます。似た名前が候補に出ます
無い参照を削除モデルに無いシェイプ・ボーンへの参照をデータから消します（確認が出ます）。大小文字だけの違いは、改名で直すので残ります
変更のある点だけベイク未ベイク・ベイク後に変更・シェイプが消えた点だけ焼き直します（速い）。編集状態は先に抜けます
全部ベイクし直す全レイヤー・全点を焼き直します。時間がかかることがあります

よく出る項目

表示される内容区分意味と直し方
基準ボーン「…」がモデルにありませんエラーセットアップタブで基準ボーンを選び直します（「自動検出」）
シェイプ「…」がモデルにありません。0 として扱われます警告モデルのシェイプ名が変わった可能性。候補があれば「候補で一括改名」、不要な参照なら「無い参照を削除」
「…」は大文字小文字が違います（モデルでは「…」）警告「候補で一括改名」で直します。名前は大文字小文字を区別します
