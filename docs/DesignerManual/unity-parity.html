Unity との見た目の一致

最終更新日: 2026-09-30

Maya のプレビューは、ゲーム（Unity / MS2026）と同じ見た目になるように作られています。Maya で決めた見た目がゲームでズレないことが、このツールの一番大事な約束です。

同じにしているもの

項目どうしているか
影・線の計算式Maya と Unity で同じシェーダーのプログラムを使っています（片方だけ直ってズレる、が起きません）
色の扱いゲームと同じ色の計算方法（リニア）と、同じ明るさの圧縮（トーンマップ）を使います
パラメータの色Unity のインスペクターと同じ値です
テクスチャ色のテクスチャとマスク用のテクスチャで、ゲームと同じ読み方をします
カメラの画角ゲームのカメラと同じ縦の画角（今は 40°）で見られます（プレビュー設定のカメラボタン）
画面上の線（インナーライン・外側輪郭・透かし線）線を出す場所の判定に、ゲームと同じプログラムを使っています
影の安定化（チラつき防止）プレビュー設定の「Unity の影の安定化を掛ける」で、ゲームと同じ計算の追従を確認できます
キャラクター用のライトゲームと同じ向き・色のライトで照らします。プレビュー設定で向きを変えて確かめることもできます（「ゲームと同じ」で戻る）

環境プロファイル

ゲームの明るさの扱い・ライト・カメラの設定を「環境プロファイル」としてまとめ、プレビューはそれに合わせて表示します。今は ms2026_ingame（ゲーム中の画面）を使っています。

MS2026 はまだ開発中なので、ゲーム側の設定（明るさの扱い・カメラなど）は変わることがあります。変わったときは環境プロファイルが更新され、プレビューも追従します。デザイナーの作業は変わりません。

一致しないもの（ゲームで確認してください）

項目理由
描く順番（眉を髪の上に出す など）Maya では描く順番を指定できないため。ゲームでは設定どおりに描かれます
他の物からキャラクターに落ちる影ゲームの影の仕組みは Maya では再現しません
画面全体の効果（光のにじみ＝Bloom、周辺減光＝Vignette）ゲーム画面全体に掛かる効果のため
髪越し表示（ステンシル）Maya では描く順番を指定できないため。Maya では「手前に出す」で代わりに確認します
接地影の地面Maya では足元の板に簡易表示します（地面が無いので背景に落ちます）。影の形・濃さの計算はゲームと同じです
セルフシャドウの細かい形・ぼけ影のデータ（シャドウマップ）の解像度・ぼかし方が Maya と Unity で違うため。どこに影が落ちるかは同じです
画面上の線を使っているときのギザギザ線を使っている間は Maya のビューポートのアンチエイリアスが効きません（ゲームでは画面全体のアンチエイリアスが掛かります）

髪の内側に暗い帯が見えるとき

片面だけのポリゴン（髪の房など）の裏側から線が見えている状態です。ゲームでも同じように見えます。気になる場合は、その部位を両面表示にする（ルックタブ › 共通 › 両面表示）か、モデル側で裏面を作ってください。
