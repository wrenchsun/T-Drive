T-Drive デザイナーマニュアル

最終更新日: 2026-10-03

このマニュアルは、T-Drive Toon（Takeda-Driven Re: IDE Visual Environment、 Maya 2026 でセルルック＝アニメ調のキャラクターの見た目を作るツール）をデザイナーが使うためのガイドです。プログラムの知識は必要ありません。

T-Drive Toon とは？（30秒で分かる説明）

3D のキャラクターをアニメの絵のように見せるための「見た目の設定」を、Maya の上で作って確かめる道具です。

  • キャラクターを「顔」「髪」「目」などの部位に分けて登録します
  • 部位ごとに影の色・影の出方・線の太さなどを調整します（例: 顔だけ影を弱くする）
  • A 案と B 案を並べて比べて、良い方を採用できます
  • 作った設定はそのまま Unity（MS2026）で同じ見た目になるように作られています
大事な考え方: 3D として正しいかより、絵として伝わるかを優先します。「顔に影を落とさない」「眉を髪の上に出す」のような“アニメ的な嘘”を、キャラクターごと・部位ごとの設定として持つのがこのツールの役目です。
Maya と Unity で同じ見た目: Maya のプレビューは、ゲーム（Unity）と同じ計算式・同じ色の扱い・同じカメラの画角で表示します。Maya で決めた見た目が、そのままゲームで出ることを目指しています。詳しくは Unity との見た目の一致。

ページ一覧

  • はじめに（導入）

    インストーラーでの導入、プロジェクトフォルダ、初回だけ必要な設定、毎回の起動方法。

  • 更新のしかた

    新しい版の確認・更新・元に戻す・更新後の確認。

  • 部位の登録

    キャラクターを「顔」「髪」などに分ける。Toon 表示の切り替え。

  • 見た目のパラメータ

    影・固定色・線・マスクの意味と、頂点カラーの塗り方のルール。

  • A/B 比較

    2 つの案を同じ条件で見比べて、良い方を採用する。

  • プレビュー設定

    ゲームと同じ条件・カメラ・ライトで見る。ライトを回して影の動きを確認。

  • キャラクター設定

    表情パラメータ・奥行き圧縮・画面上の線・接地影・影の安定化など、キャラクター全体に掛かる設定。

  • 機能のオン/オフ

    使う表現だけをオンにする。Unity ではその分だけ入った専用シェーダーになり軽くなる。

  • 表現のレシピ

    眉を前髪の上に・顔の影を綺麗に・鼻を線に・目のハイライト固定・インナーライン・天使の輪。

  • Unity 出力

    見た目の設定とモデル（FBX）を Unity 用に書き出す。

  • FacialController

    カメラの角度に合わせて顔の形を補正する。何のための機能か・作業の流れ・用語。

  • FacialController: はじめに

    新規・開く・保存、編集ボタン、セットアップタブの各項目。

  • FacialController: グリッド

    格子の見方、点の操作、他のデータからコピー、ベイク、プレビュー。

  • FacialController: ポーズ

    1 点のポーズの作り方（シェイプ・ボーン）、アニメから読み込む、土台の表情。

  • FacialController: シェイプ

    シェイプを作る・直す道具（彫る・左右に分ける・ミラー・写す・整理）。

  • FacialController: レイヤーと検証

    感情レイヤー、検証タブの見方と直し方。

  • FacialController: 出力と Unity

    Unity 向け出力と、Unity での使い方・調整、Timeline、D-Drive での使用。

  • Unity との見た目の一致

    何が一致して、何が一致しないか。

  • 困ったとき

    Toon 表示にならない・色がおかしい・Maya が固まった など。
