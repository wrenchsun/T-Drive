Unity 出力

最終更新日: 2026-09-28

作った見た目を Unity（MS2026）に渡すためのファイルを書き出します。エディタ上部の Unity 出力 を押すだけです。

書き出されるもの

ファイル中身
build/unity/<キャラクター>/<キャラクター>_<案>.materialdata.json見た目の設定（部位ごとの影・線・色など）。Unity 側で D-Drive のマテリアルデータになります
build/unity/<キャラクター>/<キャラクター>.fbxモデル。Toon マスク（頂点カラー）とスムーズ法線が Unity で読める形で入ります

使い方

  1. エディタ上部の Unity 出力 を押す
  2. A/B の案（バリアント）がある場合は、どの案を書き出すか選ぶ（ふだんは base）
  3. ボタンが「出力中…（FBX）」になります。その間も Maya は普通に使えます（1 分ほどかかります）
  4. 終わると書き出したファイルの場所が表示されます
開いているシーンは変わりません。 Unity 用に頂点カラーや UV の並びを整える作業は、裏で別の Maya（画面なし）がシーンのコピーに対して行います。
「注意 ○ 件」と出た場合は 詳細 を見てください。よくあるのは「スムーズ法線が未ベイク」です。角で線が割れて困る部位は、部位タブで スムーズ法線を焼く をしてから書き出し直してください（そのままでも書き出しはできます）。
