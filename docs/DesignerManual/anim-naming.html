命名タブ

最終更新日: 2026-10-23

MS2026（Unity）の名前の決まりに、シーンの名前が合っているかを調べて、直す案を出します。名前を変えるだけで、マテリアルの割り当てやスキンは変わりません。

Animation タブの上で、先に animset を作っておいてください（はじめかた）。ModelId の名前が、提案する名前に使われます。

名前の決まり

種類決まり例（ModelId = MisotenChara）
メッシュSK_<ModelId>_<部位>（動かさないものは SM_）SK_MisotenChara_Body
マテリアルM_<ModelId>_<部位>M_MisotenChara_Hair
テクスチャT_<ModelId>_<部位>_<種類>（種類: BaseColor / Normal / Mask / Emission / MatCap / Sdf）T_MisotenChara_Face_BaseColor.png
クリップA_<ModelId>_<動作>（動作のあとに方向 _F/_B/_L/_R、連番 01 を付けられる）A_MisotenChara_Run_F
ジョイントmGear の名前のまま（変えません）spine_C0_0_jnt

使えないもの: 日本語・全角文字・半角スペース・# % & +・@・先頭の数字・test や aaa のような捨て名・Maya の自動名（pCube1 polySurface3 lambert2）・版の接尾辞（_v2）。Model@Anim.fbx のような「@ で分ける」書き方は使いません。

検査と改名

  1. 検査を押す — メッシュ・マテリアル・テクスチャ・クリップの名前を調べて、一覧に出します（シーンは変わりません）
  2. 一覧の見方 — ❌は「このままだと出力できない」問題、⚠は「直すのがおすすめ」です。「提案」の列に直した名前が出ます
  3. 提案が気に入らなければ、提案の欄を直接書き換えられます。規則に合わない名前は赤くなります
  4. 直したい行にチェックを入れてチェックした提案を適用を押す — まとめて改名します。戻し方は 3 通りに分かれます: ①メッシュ・マテリアルの名前と、プレビュー用シェーダーの追従は、T-Drive のウィンドウでの Ctrl+Z 1 回（ビューポートでの Ctrl+Z でも同じ）で戻ります。ツールの操作（クリップ名の変更など）と合わせて、新しいものから順に戻ります。間に別の Maya の操作を挟んだときは戻さず、「先にビューポートで Ctrl+Z を押してください」と出ます。②クリップ名も、T-Drive のウィンドウで Ctrl+Z 1 回で、まとめて戻ります。③Lookは、Toon で Look を開いていればその Look に反映され（未保存の印が付き、Toon の Ctrl+Z で戻せます）、開いていなければ looks/*/look.json を直接書き換えます。ファイルの書き換えはどちらの Ctrl+Z でも戻りません。書き換える前に、ファイル名と箇所数を見せて確認します（既定は「いいえ」。「いいえ」なら Look は旧い名前のままなので、あとで Toon で Look を開いてから改名を適用し直してください）
  • 上の検索欄で一覧を絞り込めます。「❌ だけ」で、出力を止める問題だけを見られます
  • 行を右クリックすると、名前や提案のコピー、提案への貼り付け、シーンで選ぶ、ができます
  • マテリアルを改名すると、Toon の Look に書かれたマテリアル名も一緒に直ります。Toon タブで Look を開いていれば未保存の変更として残るので、Toon タブで保存してください。Look を開いていないときは、プロジェクトの looks/<キャラクター>/look.json を直接直します
  • 一度「検査」したあとは、Maya で名前を変えたり、Ctrl+Z / Ctrl+Y を押したり、フレームレートを変えたりすると、一覧・シーン設定・掃除候補が約 0.3 秒後に自動で作り直されます（「検査」を押し直す必要はありません）
  • Toon 表示用の …_tdToon マテリアルは検査の対象外です（ツールが作り直します）。改名には追従します
  • テクスチャの検査は、メッシュに割り当てられたマテリアルにつながっているものだけが対象です（どの面にも使われていないマテリアルのテクスチャは出ません）。ファイル名が uuid のようで部位が分からないときは、つながっているマテリアルの名前から部位を推定します（HairM → Hair）
  • テクスチャは提案だけです。ファイル名も変わってしまうので、適用はしません。ファイルの名前を変えるときは、自分でお願いします（仮の決め）
元のマテリアルや割り当てを壊す処理はありません。参照したファイルの中のノードは改名できないので、スキップされます（理由が結果欄に出ます）。

シーン設定

掃除候補

使われていないマテリアル・テクスチャのノード・空のネームスペースを一覧に出します。最初はどれもチェックされていません。消したいものにチェックを入れて（削除の前に確認が出ます。T-Drive のウィンドウでも Maya のビューポートでも Ctrl+Z で戻せます）「チェックしたものを削除」を押します（1 回の Undo で戻せます）。割り当て済みのマテリアルは候補に出ません。

Humanoid 対応表

Unity の Humanoid（人型）のボーン名と、Maya のジョイントの対応表です。mGear の名前は Unity の自動判定では外れやすいので、ここで決めたものをモデル出力のときに一緒に書き出します。

  1. ジョイントから推定 — mGear の名前（arm_L0_0_jnt など）から自動で埋めます
  2. 足りない所は、表のジョイント欄に直接入力するか、ビューポートでジョイントを選んで選択中のジョイントを入れる
  3. 保存 — プロジェクトの anim/<ModelId>/humanoid.json に保存

表の下に検証の結果が出ます。必須の 15 ボーン（Hips・Spine・Head・両腕の上腕/前腕/手・両脚の太もも/すね/足）が埋まっていること、同じジョイントを 2 か所で使っていないこと、親子の順序が人型と矛盾しないこと、を調べます。髪・スカート・舌など対応表に入らないジョイントは「extra」として Unity にそのまま持ち込まれます。

規則を変えたいとき

プロジェクトの anim/_naming.json（接頭辞・禁止語・部位の言い換え）と anim/_vocabulary.json（動作の語彙を足す）で、規則を上書きできます。ファイルが壊れていても、警告が出るだけで既定の規則で検査を続けます。

動作の語彙は Idle / Walk / Run / Jump / Fall / Land / Interact / Stunned / Win / Lose / Damaged / Wave / Talk / Pose です。語彙にない動作名は⚠（直さなくても出力できます）。
