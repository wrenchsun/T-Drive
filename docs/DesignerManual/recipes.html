表現のレシピ（アニメ的な“嘘”の作り方）

最終更新日: 2026-09-28

よく使う表現を、このツールの機能の組み合わせで作る手順です。どれも「3D として正しいか」より「絵として伝わるか」を優先します。

眉・目を前髪の上に出す

  1. 眉・目・アイラインの部位のロールを 眉 / 目 / アイライン にする（初期値で少し手前に出ます）
  2. 足りなければルックタブ › 手前に出す量 (m) を少しずつ上げる
  3. プレビュータブで 横 カメラにして、眉が頭の外に出ていないか確認
眉と顔が同じマテリアル（顔のテクスチャに眉が描いてある）場合は部位を分けられません。モデル側で眉のポリゴンを別マテリアルに分けてください。

顔の影を綺麗にする

  1. ロール 顔 で影の強さが弱め（0.35）になっています。さらに弱めたいときはルックタブ › 影の強さ
  2. 影が細かく割れるときは 顔の法線 で楕円体に寄せる
  3. 「ここは影にしたくない」所は Toon マスク の B を黒（常に明るい）
  4. 「ここは常に影」（首の下・目の周り・前髪の下）は R を黒

鼻を線にする・鼻の影を消す

3D の鼻は影が強く出て「鼻の立体」が目立ちます。アニメでは鼻は一本の線か小さな点で表現します。

  1. 鼻の影を消す: 部位タブで顔を選び、Toon マスクの B を押して鼻の周り（鼻筋・小鼻・鼻の下）を黒で塗り、確定。どの向きのライトでも鼻に影が出なくなります
  2. 鼻の線を消す: 同じく G を押して鼻の周りを黒で塗る（輪郭線が鼻で出っ張らなくなります）
  3. 鼻を線で描く: 顔のテクスチャ（ベースマップ）に鼻の線を描き込みます。線はテクスチャなので、ライトやカメラに関係なく同じ形で出ます
  4. 鼻の下にだけ小さな影を出したいときは、鼻の下の頂点だけ R を黒で塗ります（常に影）
頂点が少なくて鼻の周りだけ塗れないときは、ルックタブ › マスク › Toon マスク (RGBA) にテクスチャを指定すると画素単位で指定できます（見た目のパラメータ）。

目のハイライトをライトに関係なく固定する

  1. 目の部位のロールを 目 にする（初期値で影なし・線なし・ライト色の影響 0）
  2. ハイライトは目のテクスチャに描き込む（または別メッシュにして同じく目のロールにする）
  3. プレビュータブで ライト回転 しても目の見た目が変わらないことを確認

インナーライン（服のしわ・髪の束の内側の線）

外側の輪郭線（アウトライン）とは別に、モデルの内側にも線を入れると作画らしさが上がります。方法は 2 つあります。

  • 画面上の自動の線: キャラクタータブの「画面上の内側の線（インナーライン）」。部位の境界・口などの折れ目・髪の束の重なりに、距離によらず一定の太さの線が自動で出ます。手軽で、Maya でもゲームと同じ見た目で確認できます
  • テクスチャに描き込む（下の手順）: 服のしわ・模様など、形の境目ではない所に線を入れたいとき

テクスチャに描き込む

  1. ベースマップ（色のテクスチャ）に、しわ・境界・髪の束の線を直接描く
  2. 線の色は真っ黒ではなく、その場所の色の暗い版にする（輪郭線の「線色にベース色を混ぜる」と揃えると馴染みます）
  3. カメラを引いたときに線が潰れる場合は、線を太めに描くか、線の部分の UV を大きく取る

UV を直線に並べる方法（本村線）

線を入れたい辺の UV を縦か横の一直線に並べ、テクスチャ上で線をピクセルの格子に沿わせると、どの距離でもにじみにくい均一な線になります。

  1. Maya の UV エディタで、線を入れたい辺のループを選び、UV を水平（または垂直）にそろえる
  2. テクスチャ上でその直線に沿って 1〜2px の線を描く
  3. プレビューで距離を変えて、線の太さ・にじみを確認

髪にハイライト（天使の輪）を入れる

  1. 髪の UV に合わせて、ハイライトの帯を白黒のテクスチャ（R チャンネル）で描く
  2. ルックタブで髪を選び、髪ハイライト › ハイライトの帯（R） にそのテクスチャを指定
  3. ハイライト色 を決め、視線で帯をずらす量（0.1〜0.3）でカメラの上下に合わせた動きを付ける
