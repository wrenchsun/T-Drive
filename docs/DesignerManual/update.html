更新のしかた

最終更新日: 2026-10-14

T-Drive Toon はリリース版（v0.1.0 のような番号の付いた版）だけが配られます。新しい版が出ると Maya の中で知らせが出るので、下の手順で更新します。

新しい版の知らせ

  • Maya の起動時に1 日 1 回確認し、新しい版があればビューポートの上に「T-Drive Toon の新しい版 vX.Y.Z があります」と出ます
  • いつでも Tools › T-Drive › 更新… の「最新の版を確認」で確かめられます
  • 外部ツール（下の「外部ツール」）に新しい版があるときは、本体とまとめて 1 つのメッセージで出ます。例: 「更新があります（本体 v0.6.0 / MS2026 グレーボックス v1.1.0）（Tools › T-Drive › 更新…）」。本体だけのときは今までどおりの文言です
  • 知らせが不要なら、更新ウィンドウの「Maya の起動時に更新を確認する」を外します

更新する

この節は T-Drive 本体の更新です。外部ツールは下の「外部ツール」を見てください。

  1. 編集中の Look を保存する（念のため。更新しても未保存の変更は残ります）
  2. Tools › T-Drive › 更新… を開き、最新の版を確認 を押す
  3. 一覧から版を選ぶと、その版までの変更点が表示される。互換性の欄を読む
  4. この版に更新 → 確認で「はい」
  5. ツールが読み込み直され、プロジェクトの Look の確認が自動で行われる。問題が無ければ完了
版の種類意味更新してよいか
PATCH（例: 0.1.0 → 0.1.1）不具合の修正いつでも
MINOR（例: 0.1.0 → 0.2.0）機能の追加。今までの Look はそのまま同じ見た目いつでも
MAJOR（例: 1.x → 2.0）今までの Look・データの扱いが変わる担当者に確認してから。赤い警告と移行ガイドの案内が出ます
「Maya の再起動が必要です」と出たときは、Look を保存してから Maya を再起動してください。

元に戻す

更新して困ったときは、更新ウィンドウの 前の版に戻す を押します。もう一度押すと、戻す前の版に戻ります。 それより前の版にしたいときは、一覧から古い版を選んで「この版に更新」を押します（古い版にするときは、その版より後に入った変更が表示されます）。

外部ツール

T-Drive 本体とは別のリポジトリで配られるツール（例: MS2026 グレーボックス）を、URL を入力して追加できます。追加すると Maya の再起動なしでタブ（や Tools のメニュー）が出ます。更新ウィンドウの 外部ツール 区画（「更新」の下、「更新後の確認」の上）で扱います。

配布担当が最初から入れてある場合は、追加の操作は要りません（はじめに）。

一覧の列:

列意味
名前ツールの名前。開発者の clone を使っているものは「（開発用）」が付きます
今の版入っている版
固定タグ固定している版のタグ（追加時にタグを入れなければ、そのときの最新のリリース）
最新の版「最新の版を確認」を押したあとに出ます（押すまでは「-」）
上げ幅PATCH / MINOR / MAJOR（色の意味は上の表と同じ）
有効有効 / 無効

外部ツールを追加する

  1. Tools › T-Drive › 更新… を開き、「外部ツール」の URL を入力して追加 を押す
  2. ツールのリポジトリの URL（https://github.com/…/….git）を入れる。タグは空のままなら最新のリリース（入れるなら v1.2.0 の形）
  3. OK を押すと取得して、その場で読み込まれる。タブ（や Tools のメニュー）が出ます
最初の外部ツール: MS2026 グレーボックス https://github.com/wrenchsun/MS2026-Maya.git。T-Drive v0.6.0 以上が必要です。タブには案内文と「グレーボックスのウィンドウを開く」ボタンがあり、実際の作業は Tools › MS2026 のウィンドウで行います。

外部ツールを更新する

  1. 一覧からツールを選び、最新の版を確認 を押す（「最新の版」「上げ幅」の列が埋まる）
  2. 最新の版に更新 を押すと、下の欄に変更点が出る。互換性を読み、確認で「はい」（MAJOR のときは「変更点（互換性）を読みましたか？」と聞かれます。担当者に確認してから）
  3. 更新したら、メニュー Tools › T-Drive › ツールをリロード を実行して反映する（未保存の Look などは残ります）。「Maya の再起動が必要です」と出たときは、保存してから再起動

外部ツールを元に戻す

元に戻す を押すと、1 つ前の版に入れ替わります（もう一度押すと戻す前の版）。そのあと ツールをリロード で反映します。

外部ツールを無効にする / 有効にする

無効にする を押すと、次のリロード・起動から読み込まれません（ファイルは残るので、あとで戻せます）。有効にする を押すと、その場で読み込まれます。

外部ツールを削除する

削除 を押し、確認で「はい」。ツールのフォルダ（%LOCALAPPDATA%\TDriveToon\tools\<id>）ごと消えます。開いているタブは、ツールをリロード するまで残ります。

「（開発用）」のツール

開発者が自分の clone を登録しているツール（フォルダを直接指している、またはブランチ上にあるもの）です。更新・元に戻すは押せません（ボタンの説明に理由が出ます）。開発者が git で更新してください。削除しても、開発者の clone のフォルダは消えず、一覧から外れるだけです。

更新後の確認

更新ウィンドウの プロジェクトの Look を確認する は、プロジェクトの全 Look を新しい版で読み込んで、問題が無いかを調べます（保存はしません）。 更新した後にまだ確認していないと、Maya の起動時に「更新後の確認がまだです」と出ます。

インストーラーでの更新

Install-TDriveToon.bat をもう一度ダブルクリックしても、最新の版に更新されます（Maya は閉じておく）。更新ウィンドウが開けないときはこちらを使ってください。

うまくいかないとき

表示対処
「確認できませんでした: …時間切れ」「…権限」ネットワークと、GitHub の wrenchsun/T-Drive を見る権限を確認。インストーラーをもう一度実行すると、GitHub のログイン画面が出ます
「開発用（ブランチ …）。更新は git で」開発用の導入です。更新ウィンドウでは更新しません（開発者は git で更新）
「ツール本体に変更があります」ツール本体のフォルダ（%LOCALAPPDATA%\TDriveToon\T-Drive）を触ってしまっています。フォルダごと消してインストーラーを実行し直してください（プロジェクトのデータは消えません）
外部ツールの追加で「取り込めませんでした: …」URL が違う、見る権限が無い、ネットワークに繋がっていません。URL（末尾が .git）とタグを確かめてください。何も追加されません
「外部ツールとして使えません: …」（tool.json が無い など）T-Drive 用の外部ツールではないリポジトリです。ツールの作者に確認してください。何も追加されません
「…は追加できません: …」（T-Drive の版が足りない）そのツールが必要とする T-Drive の版より、入っている本体が古いです。上の手順で本体を更新してから、もう一度追加してください（MS2026 グレーボックスは v0.6.0 以上）。何も追加されません
「…は導入済みです」「…が既にあります」同じツールがすでに入っています。更新するなら「最新の版に更新」、入れ直すなら「削除」してから追加してください
「…は開発用（絶対パスの clone）です。更新は git で」開発者の clone です。更新ウィンドウでは更新しません
「更新後の確認で問題が見つかりました」表示された内容を担当者に報告し、必要なら「前の版に戻す」
