キャラクター設定（キャラクタータブ）

最終更新日: 2026-09-28

部位やマテリアルではなく、キャラクター全体に掛かる設定です。多くはゲーム（Unity）側の仕組み（T-Drive の Unity パッケージのコンポーネントや画面効果）が使うもので、Maya では見た目を確認できません。そうした項目には （Unity でのみ） と表示されます。値は Look に保存され、Unity に渡ります。

項目が見当たらないときは、機能タブでその機能がオフになっています（オフの機能の欄は隠れます）。
項目意味Maya で確認
キャラクターライトの安定化（平滑化・ヒステリシス）ライトが少し動いたときに影の境界がチラつかないようにします。平滑化 = 影が追いつくまでの時間、ヒステリシス = この角度より小さい変化は無視できる（プレビュータブ › Unity の影の安定化を掛ける）
髪越し表示（ステンシル）眉・目・アイラインを前髪の上に、顔の輪郭からはみ出さずに出しますできない。Maya では 手前に出す で代わりに確認
画面上の内側の線（インナーライン）部位の境界・折れ目（口など）・髪の束の重なりに、画面上で一定の太さの線を足します。線を出す部位 にチェックした部位と、その隣の部位との境界に出ますできる（ゲームと同じ計算）。半透明の部位には出ません。テクスチャで描く線は 表現のレシピ
接地影足元に影を残して、キャラクターが浮いて見えないようにします。半径 = 足からの影の広がり（m）、濃さ = 足元の暗さ。足を上げると薄く小さくなります簡易表示（足元に影の板を置きます。地面が無いので背景に落ちます。モデルの書き出しには入りません）
奥行き圧縮顔を平面的にして、2D の作画に近づけます。量 をここで、効かせる部位 をルックタブ › 手前に出す › 奥行き圧縮の効かせ具合（例: 顔だけ 1）で決めますできる
顔影マップ（SDF）ライトの角度に応じて、顔の影が「作画どおりの形」で進むようにします（下の手順）できる
カメラ角度補正正面・3/4・横で顔の形を補正する BlendShape（下の手順）できる（カメラに連動）
表情パラメータ「頬の赤み」のような名前を付けたつまみ（0〜1）と、それで動かす値の対応表。ゲームでは表情に合わせてこのつまみを動かしますできる（プレビュー）

顔影マップ（SDF）の作り方

顔の影は法線だと形が崩れやすいので、「ライトがこの角度のとき、顔のどこまでが明るいか」を絵として描いて決めます。

  1. 顔の UV に合わせて、右からライトが当たるときの明るい範囲（白）・影（黒）の白黒マスクを角度ごとに描く。ファイル名に角度を入れる: face_shadow_000.png（正面から）, face_shadow_045.png, … face_shadow_180.png（真後ろから）
  2. 角度が大きいほど白い範囲が狭くなるように描く（前の角度の白の内側）
  3. キャラクタータブ › 顔影マップ（SDF） › マスクから生成… でフォルダを選ぶ → 1 枚のマップ（face_shadow_sdf.png）ができ、顔に設定されます
  4. プレビュータブの ライト回転 で、影が描いたとおりの形でなめらかに進むか確認。効かせ具合はルックタブ › 顔影マップ（SDF）
左からのライトは、マップを左右反転して使います（顔の UV が左右対称である前提）。

カメラ角度補正の作り方

横顔や 3/4 で「目を前に出す」「鼻を短くする」「輪郭を整える」など、角度ごとに顔の形を作画的に補正します。

  1. 顔のメッシュを選択して、横（など補正したい角度）の 作る → 顔の複製（…_vc_side）が横に並びます
  2. その複製を彫る（頂点を動かす。頂点数は変えない）
  3. 登録 → 顔メッシュの BlendShape になります
  4. カメラに連動（プレビュー） → ビューポートでカメラを回すと、角度に応じて補正が自動で混ざります（正面 0°・3/4 45°・横 90°）
  5. 確認が終わったら 連動を外す（ゲームでは Unity 側が同じ計算で混ぜます）
彫った複製（…_vc_…）は Unity 出力の FBX には入りません（BlendShape として顔メッシュに入ります）。

表情パラメータの作り方

  1. 追加… で名前を付ける（例: blush）
  2. 行を追加 → マテリアル（例: face）・パラメータ（例: 固定色の強さ _ToonTintStrength）・0 のとき / 1 のときの値を決める
  3. プレビュー のスライダーで見た目を確認（保存はされません）。Look の値に戻す で元に戻ります
頬の赤みを固定色で出す場合は、先に Toon マスク の A を頬に黒く塗っておく必要があります（固定色は A を黒く塗った場所にだけ乗ります）。
