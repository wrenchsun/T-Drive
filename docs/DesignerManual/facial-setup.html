はじめに（セットアップタブ）

最終更新日: 2026-10-05

最初にデータを作り、顔のメッシュ・基準ボーン・格子などを決めます。ここで決めた内容が、以降のすべての作業のもとになります。

エディタを開く

  1. 顔のブレンドシェイプが付いたモデルを Maya で開きます
  2. T-Drive › エディタ を開き、1 段目のタブで FacialController を選びます
  3. 2 段目のタブは左から セットアップ / グリッド / ポーズ / シェイプ / レイヤー / 検証 / 出力。シェイプタブはシェイプのページを見てください

新規・開く・保存

画面の上に データ: … の行と 4 つのボタンがあります。保存していない変更があると ●未保存 と出ます。

ボタンはたらき
新規新しいデータを作ります。キャラクター ID（英小文字・数字・_ だけ）・対象メッシュ（ブレンドシェイプのあるメッシュ。選択中のものが初期値）・プロファイル（あとで変えられます）を決めます
開く保存したデータを開きます
保存 / 別名で保存データを保存します。Maya のシーンを保存すると、どのデータを開いていたかも覚えられ、開き直すと同じデータが開きます

データはプロジェクトフォルダの中の facial\<キャラクター>\<キャラクター>.fcpose.json に保存されます（プロジェクトははじめに（導入））。Toon の Look とは別のファイルです。

「編集」ボタン

データの下にある 編集 ボタンは、ポーズを作るためのスイッチです。

  • オン — シーンが基準姿勢（バインドポーズ・シェイプの重みがすべて 0）になります。グリッド / ポーズタブで点のポーズを作れます。画面には 編集中 と出ます
  • オフ — 元の姿勢（表情やアニメの途中の姿）に戻ります
グリッドで点をクリックしても、自動で編集が始まります。編集中は顔の表情が消えて見えますが、故障ではありません。オフにすれば戻ります。
編集がオンのままシーンを保存しても大丈夫です。保存の直前に元の姿勢へ戻し、保存が終わると編集に戻ります（選んでいた点・スライダーの値はそのまま）。ファイルには元の姿勢が入ります。Maya の自動保存での動作は確認中なので、大事な作業の前は「編集」をオフにしてから保存すると確実です。
「編集」をオンにできないとき: 編集に入るとき、顔に効くジョイントだけを基準姿勢（バインドしたときの位置）に置きます。体のジョイントには触りません。もともと基準姿勢にあるキャラクターでは、何も動かしません。基準姿勢の形が、スキンを掛ける前のメッシュと合わないと、理由を表示して止まります（ずれたまま焼くと、補正にそのずれが入るためです）。顔のジョイントにキーや接続が付いていないか、メッシュの頂点を直接動かしていないかを確かめてください。
編集のまま放置しないでください。エディタを閉じる・ツールをリロードする・別のシーンを開くと元の姿勢に戻りますが（タブを切り替えただけでは戻りません）、作業が終わったらオフにする習慣をつけると安全です。

「顔の補正」のチェック（補正のオン / オフ）

「編集」ボタンの右の顔の補正で、カメラの角度に合わせた補正（プレビュー）を止めたり戻したりできます。同じチェックが、Toon タブの「表示: Toon / 元の見た目」の右にもあります。Toon の作業中に、顔の補正だけを止めたいときに使います。

ヘッダーの表示いまの状態
編集中 = シーンが基準姿勢になっています「編集」がオン。補正は止まっています（「顔の補正」は灰色）
プレビュー中 = カメラの角度に合わせて顔を補正しています「編集」がオフで、補正が掛かっています
顔の補正はオフです（元の顔）プレビューはあるが、補正を止めています
編集していません（シーンは元の顔のままです）プレビューがありません（「顔の補正」は灰色）
  • グリッドタブのプレビューの欄の「補正あり / 補正なし」ボタンと同じ状態です。どこで切り替えても、ほかの 2 か所も変わります
  • オフにしても、プレビューの仕掛けは残ります。チェックを入れ直せば、すぐ戻ります

セットアップタブの項目

項目意味
対象のメッシュ › 顔のメッシュ補正を焼き込む顔のメッシュ。「選択から」で Maya で選んでいるメッシュに変えられます
ネームスペースキャラクターをリファレンス（別のファイルを参照して読み込む方法）で使うと、ノードの名前の頭に chr: のような名前（ネームスペース）が付きます。顔のメッシュが 1 か所だけ見つかれば、自動で選ばれます（「ネームスペース chr: のキャラクターを使います」と出ます）。同じキャラクターが 2 体いるときは、ここで選びます。「自動で探す」で探し直せます。データには書かれず、このシーンだけに覚えます（同じデータを、別のシーンや Unity でそのまま使えます）。リファレンスのキャラクターでは、焼いた補正のシェイプは、シーン側に作る専用のノード（tdFacial_…）に入ります
追加のメッシュまつ毛・眉など、顔と一緒に補正したい別メッシュ。「選択から追加」「外す」で増減
LOD のメッシュLOD1 以降の（頂点数の違う）メッシュ。「選択から追加」で足し、LOD の番号は表で直せます。顔のメッシュと同じポーズを当てて、そのメッシュの形の差分を、同じ名前のシェイプとして焼きます。LOD のメッシュにも、ポーズで使うシェイプが同じ名前で必要です（無いものは、そのメッシュでは動きません。検証タブに出ます）。LOD をあとから足したときは「ベイク（全部）」で焼いてください。Unity では、同じ重みがすべての LOD のメッシュに書かれます
基準ボーン頭のボーン。「自動検出」で名前から探します。「選択から」で Maya で選んでいるジョイントにもできます
顔の前方向顔が向いている方向（基準ボーンの軸）。Maya は Y が上なので +X / −X / +Z / −Z から選びます
中心のずらし(cm)格子の中心を基準ボーンからずらす量。通常は 0 のままで構いません
格子点の数（列 × 行）、角度の範囲（Yaw / Pitch の全体の幅）、端のフェード（格子の端で補正をなめらかに弱める角度）。「適用」で変更。作った点は角度で引き継がれ、新しい格子に乗らなくなるキーは、先に確認が出ます
ミラー（左右反転）「使う」をオフにすると、左右反転の貼り付け・自動生成の鏡映ができません。名前の末尾（左 _L / 右 _R）、反転しないもの（名前にこの文字を含むものは反転しない。カンマ区切り）、ボーンの反転軸
自動生成とベイク作り方: IDW（まわりのキーをなめらかに混ぜる）か最近傍（いちばん近いキーをそのまま使う）。べき乗（IDW）: 大きいほど近いキーの影響が強い。ベイクのしきい値: これより小さい頂点の動きは捨てる
命名規則プロファイルシェイプ名の決まり（左右の名前・動かせる範囲・標準のシェイプ）。ARKit 52 / VRChat ビセム / MetaHuman / shizuku が付属。選んで「適用」すると左右の名前と動かせる範囲が入ります。「上書き」をオンにすると、このキャラクターで変えた範囲もプロファイルの値になります。足りない標準シェイプの数も表示されます
Toon のカメラ角度補正（T-20）「カメラ角度補正（T-20）から取り込む…」で、Toon のキャラクタータブで作った補正（正面 / 3/4 / 横）を、Neutral レイヤーの Pitch 0・Yaw 0 / 45 / 90° のキーにします。T-20 のデータと Look は変わりません。左側（Yaw −）は、取り込んだあとにグリッドの「自動生成」で埋めます
作業セット補正で触るシェイプとボーンにチェックを入れます（「絞り込み」「表示中を全部オン」「全部オフ」「選択中のジョイントを追加」）。チェックしたものだけがポーズタブに並びます
品質（実行時の見え方）シャープさ: 1 = そのまま。大きいほど、キーの角度のそばでキーのポーズそのものに寄ります（キーとキーの間の混ざりが減ります）。Maya のプレビューにも掛かります。コマ打ち fps: 0 = 使わない。Unity で効きます（Maya のプレビューには掛かりません）。誇張の既定の強さ（0〜1）: 重みが 1 を超えるポーズから作る誇張用シェイプをどれだけ効かせるか。プレビューの「誇張」の初期値にもなります。角度のしきい値: これより小さい角度の変化では、補正を計算し直しません（Unity の軽量化）。補間: 「双線形（標準）」か「なめらか（Catmull-Rom）」。なめらか = キーとキーの間の動きが滑らかになりますが、キーの角度以外では少し行き過ぎることがあります。キーの角度ちょうどでは、どちらも同じ結果です
Toon マテリアルに顔の角度を渡すオンにすると、プレビューが顔の向き（正面 = 0、真横 = ±1）と強さを、顔のメッシュの Toon マテリアルに渡します。Toon 側の機能「顔の角度連動」で、向きに合わせて輪郭線の太さと陰の境目を変えられます。Toon のプレビューが出ていないと、つながりません
補正から除外するもの名前に、入力した文字を含むシェイプ・ボーンは、ベイクで無視されます（部分一致）。ポーズには残り、ポーズタブでは薄い斜体で表示されます。変えると、焼いた点に「変更あり」の印（ピンクの枠）が付くので、「ベイク（変更のある点）」で焼き直してください
部位別の強さ名前に、入力した文字を含むシェイプ・ボーンの動きに、ベイクのときだけ強さ（0〜1）を掛けます（部分一致。例: eye を 0.5 にすると、目の動きが半分で焼かれます）。複数に当たるときは上の行が優先（「上へ」「下へ」で並べ替え）。「補正から除外するもの」に入れた名前は、強さに関わらず焼かれません。編集中の画面とスライダーは、元の値のままです。掛けた結果は、焼いたあとのプレビューで確かめてください。変えると、焼いた点に「変更あり」の印が付くので焼き直します。ゲームの実行中に変えることはできません（焼き込み）
社内のテスト担当向け: サンプルモデルの補助
サンプルモデル（shizuku）で試すときの補助ツールがあります。mayapy tools/setup_sample_shizuku_facial.py でサンプルのデータを作り、mayapy tools/load_sample_shizuku_anim.py anim_idle で体のアニメーション（例: 待機）を別のシーンに読み込みます。サンプルのモデル自体は、このツールには入っていません。各自で用意してください。
