はじめに（導入）

最終更新日: 2026-09-28

初回だけ必要な設定

1. ツールを Maya に登録する

リポジトリのフォルダで、次のコマンドを 1 回だけ実行します（PowerShell）。

powershell -ExecutionPolicy Bypass -File tools\install_maya_module.ps1

「Installed: …TDriveToon.mod」と出れば OK です。

2. Maya の表示方式を DirectX 11 にする

  1. Maya のメニュー Windows › Settings/Preferences › Preferences を開く
  2. 左の一覧から Display を選ぶ
  3. Viewport 2.0 › Rendering engine を DirectX 11 にする
  4. Save を押して、Maya を再起動する
DirectX 11 にしないと Toon 表示になりません。 ゲーム（Unity）と同じシェーダーの計算式を Maya でも使うために必要です。エディタ上部にオレンジ色の警告が出ている場合は、ここを確認してください。
色の設定（カラーマネジメント）はツールが自動でゲームと同じにします。自分で変える必要はありません。

毎回の起動

  1. Maya 2026 を起動すると、上部のメニューに 「T-Drive Toon」 が追加されます
  2. T-Drive Toon › エディタ でエディタが開きます

エディタのドッキング

エディタは Maya の他のパネルと同じようにドッキングできます。

  • ウィンドウ上部のタブ（「T-Drive Toon …」）をドラッグして、Channel Box / Attribute Editor の横やビューポートの端に重ねる
  • × で閉じても位置は覚えています。メニュー T-Drive Toon › エディタ で同じ場所に開きます
  • Maya を再起動しても、ドッキングしていた場所に復元されます（再起動後の復元は確認中。うまく戻らない場合はメニューから開き直してください）

テスト用シーン

リポジトリ直下の T-Drive.mb はテスト用のシーンです（テスト素体としてユニティちゃんが入っています）。開くとすでに Toon 表示になっています。

開いたときに白っぽい表示のままなら、ビューポートで キーボードの 6（テクスチャ表示）を押してください。エディタで Look を開くと自動でテクスチャ表示になります。
ユニティちゃんは確認用の素体です。ゲーム（MS2026）では使いません。ツールは特定のモデルに依存しない作りなので、本番のキャラクターでも同じ手順で使えます。
