はじめに（導入）

最終更新日: 2026-10-03

初回だけ必要な設定

1. ツールを入れる（インストーラー）

配布された Install-TDriveToon.bat を使います。

  1. Git for Windows が入っていなければ入れる（git-scm.com。初期設定のままで OK）
  2. GitHub の wrenchsun/T-Drive を見られるアカウントか、担当者に確認する（非公開のリポジトリです）
  3. Install-TDriveToon.bat を作業する Maya のプロジェクトフォルダ（workspace.mel がある所）に置く
  4. ダブルクリックする。初回は GitHub のログイン画面が出ることがあります
  5. 「導入しました: T-Drive Toon 0.1.0」と出たら Enter で閉じる
  6. Maya を起動する（起動中なら再起動）。上部のメニューに T-Drive が出れば完了
インストーラーがすること内容
ツールの取得%LOCALAPPDATA%\TDriveToon\T-Drive に取得し、最新のリリース版に固定します（開発途中の版は入りません）。このフォルダは触らないでください
プロジェクトの決定置いたフォルダが Maya のプロジェクトならそこ。違えば Maya で最後に開いたプロジェクト。どちらでもなければフォルダを選ぶ画面が出ます（プロジェクト）
Maya への登録Maya の起動時に T-Drive Toon が読み込まれるようにします
もう一度ダブルクリックすると最新の版に更新されます。普段の更新は Maya の中から行えます（更新のしかた）。
開発者向け: リポジトリをそのまま使う

このリポジトリで開発する人は、リポジトリのフォルダで次を実行します（版を固定しない。プロジェクト = リポジトリ）。

powershell -ExecutionPolicy Bypass -File tools\install_maya_module.ps1

2. Maya の表示方式を DirectX 11 にする

  1. Maya のメニュー Windows › Settings/Preferences › Preferences を開く
  2. 左の一覧から Display を選ぶ
  3. Viewport 2.0 › Rendering engine を DirectX 11 にする
  4. Save を押して、Maya を再起動する
DirectX 11 にしないと Toon 表示になりません。 ゲーム（Unity）と同じシェーダーの計算式を Maya でも使うために必要です。エディタ上部にオレンジ色の警告が出ている場合は、ここを確認してください。
色の設定（カラーマネジメント）はツールが自動でゲームと同じにします。自分で変える必要はありません。

プロジェクト

Look（見た目の設定）・Unity 出力・キャプチャはプロジェクトフォルダに保存されます。ツール本体とは別の場所です。

プロジェクトフォルダの中内容
looks\<キャラクター>\look.jsonLook
build\unity\Unity 出力
captures\A/B・パリティのキャプチャ
looks\_env\環境プロファイル（あればツール同梱のものより優先）
  • 今のプロジェクトはエディタの上部に表示されます
  • 変えるときは T-Drive › プロジェクトを選ぶ…
  • テクスチャはプロジェクトフォルダの中に置くと、どの PC でも同じシーンが開けます（パスがプロジェクト基準で保存されます）

毎回の起動

  1. Maya 2026 を起動すると、上部のメニューに 「T-Drive」 が追加されます
  2. T-Drive › エディタ でエディタが開きます。ウィンドウ上部の 1 段目のタブは Toon（見た目を作る。これまでのエディタ）と FacialController（準備中）です。普段は Toon のまま使います

エディタのドッキング

エディタは Maya の他のパネルと同じようにドッキングできます。

  • ウィンドウ上部のタブ（「T-Drive 0.4.0」のように版が付きます）をドラッグして、Channel Box / Attribute Editor の横やビューポートの端に重ねる
  • × で閉じても位置は覚えています。メニュー T-Drive › エディタ で同じ場所に開きます
  • Maya を再起動しても、ドッキングしていた場所に復元されます（再起動後の復元は確認中。うまく戻らない場合はメニューから開き直してください）

テスト用シーン（開発用のみ）

開発用のリポジトリ直下の T-Drive.mb はテスト用のシーンです（インストーラーで入れたツールには含まれません）（テスト素体としてユニティちゃんが入っています）。開くとすでに Toon 表示になっています。

開いたときに白っぽい表示のままなら、ビューポートで キーボードの 6（テクスチャ表示）を押してください。エディタで Look を開くと自動でテクスチャ表示になります。
ユニティちゃんは確認用の素体です。ゲーム（MS2026）では使いません。ツールは特定のモデルに依存しない作りなので、本番のキャラクターでも同じ手順で使えます。
