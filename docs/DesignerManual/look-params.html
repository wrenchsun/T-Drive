見た目のパラメータ

リム・MatCap などの欄が見当たらないときは、機能タブでその機能をオンにしてください（オフの機能の欄は隠れます）。

最終更新日: 2026-09-30

ルックタブの使い方

  1. 左の一覧で部位（例: face）かマテリアルを選びます。部位を選ぶと、その部位の全マテリアルにまとめて設定されます
  2. 右のスライダー・色・チェックを変えると、動かしている最中からビューポートに反映されます
  3. 気に入ったらヘッダーの 保存
操作内容
↺その項目をロールのプリセット値（無ければ既定値）に戻します
元に戻す / やり直す（Ctrl+Z / Ctrl+Y）エディタでの変更を戻します。値の変更のほか、部位の登録・ロール変更・部位名の変更・バリアントの追加/削除/採用も戻せます。エディタのどこか（どのタブでも）をクリックしてから押してください。ビューポートで押す Ctrl+Z は Maya の Undo で、Look の値は戻りません（プレビューの見た目も変わりません）
「—」表示部位の中でマテリアルごとに値が違うときの表示。操作すると全マテリアルがその値に揃います
編集先ふだんは base（基本の値）。A/B 比較用の案（バリアント）を選ぶと、その案への変更として書き込まれ、変えた項目は黄色の太字になります。横の base ボタンで基本の値に戻せます（A/B 比較）
色クリックで色を選びます。Unity のインスペクターと同じ値です
描画順オフセットと両面表示の影響の一部は Maya では再現されません（Unity でのみ効きます）。Unity との見た目の一致を参照。

影（2 段階の影）

光の当たり方で「明るい所」と「影」の 2 段階に塗り分けます。グラデーションではなく、アニメのように境界がくっきり出ます。

名前意味コツ
影色影の部分に掛ける色黒や灰色ではなく、色味をずらすとアニメらしくなります（肌 → 赤紫寄り、服 → 青寄り など）
影の境界どこから影にするか（0〜1）大きいほど影の面積が広がります
境界ぼかし境界のぼけ具合小さいほどくっきり。0.01〜0.03 くらいがセルらしい
影の強さ影をどれだけ出すか（0 = 影なし）顔は弱く（0.2〜0.4）すると綺麗に見えます

固定色（頬・耳・口の中）

光に関係なく、決まった場所にいつも色を乗せます。頬の赤み、耳の赤み、口の中を暗くする、などに使います。場所は Toon マスク の A（アルファ）で塗ります。

名前意味
固定色乗せる色（掛け算）
固定色の強さ0 = 乗せない / 1 = しっかり乗せる

線（アウトライン）

キャラクターの外側の輪郭線です。

名前意味コツ
線色線の色真っ黒より、暗い茶・暗い赤などにすると柔らかく見えます
線色にベース色を混ぜる線色に、その場所の元の色（テクスチャ）を混ぜる割合0.5 前後にすると、肌は赤っぽい線・髪は髪色の線になります
線幅線の太さ。1 = フル HD（1080p）の画面で 1 ピクセルカメラの距離を変えても画面上の太さは変わりません。画面の解像度には比例します（720p なら 2/3 の太さ）。顔は細く、髪は太めが基本
スムーズ法線を使う角ばった所で線が割れないようにする（1 = 使う）先に部位タブの スムーズ法線を焼く が必要です。焼く前は 1 でも普通の法線で描きます。形を変えたら焼き直してください
遠いほど線を細く0 = 距離に関係なく一定 / 1 = 遠いほどしっかり細く引きの画面で線がうるさいときに使います
細くし始める距離 (m)カメラからこの距離より遠くなると細くし始めます顔のアップ（1m 前後）で細くならない値にするのが基本

そのほかの表現（手前に出す・リム・髪ハイライト・ライト色）

グループ / 名前意味コツ
手前に出す（眉・目を髪の上に）／手前に出す量 (m)その部位をカメラ方向へ少しだけ寄せ、前髪越しに見えるようにします（画面上の位置は変わりません）眉 3cm・アイライン 2.5cm・目 2cm が初期値。大きくしすぎると横顔で頭の外に出るので、横からも確認してください

ライト／ライト色の影響1 = ライトの色で色が変わる / 0 = ライトの色に影響されない目（ハイライトの描き込み）は 0 が初期値。どんな照明でも目の色とハイライトが同じに見えます
リム／リム色・鋭さ・強さ輪郭のふちを明るくする（光の当たっている側だけ）強さ 0.2〜0.5 くらい。鋭さを上げると細い縁になります
髪ハイライト／ハイライトの帯（R）髪のハイライト（天使の輪など）を描いたテクスチャ。R チャンネルの明るい所にハイライト色が乗ります髪の UV に沿って帯を描いておきます。未設定ならハイライトなし
髪ハイライト／視線で帯をずらす量カメラが上から見るか下から見るかで、帯を上下にずらします0.1〜0.3 くらい。0 ならずれません
影／2 影の色・境界・強さ影の中の、さらに暗い部分（3 段階の塗り分け）。強さ 0 なら 2 段階のまま境界は影の境界より小さく（0.2〜0.3）。服のしわの奥・髪の重なりに

セルフシャドウ（キャラクター自身が落とす影）

前髪・腕・あごなどが自分の体に落とす影を、トゥーンの影（影色）として足します。機能タブで「セルフシャドウ」をオンにすると使えます（既定はオフ）。部位ごとに使う・使わないも機能タブの一覧表で選べます（部位ごとのオン/オフ）。

項目意味
影 › セルフシャドウを受ける量その部位に落ち影をどれだけ出すか（0 = 受けない）。顔は既定で 0（前髪の影で顔を汚さない。顔の影はToon マスクの R で描く）
影 › セルフシャドウを落とすその部位が他に影を落とすか（チェック）。例: まつ毛・細かい装飾・髪の毛先の影を消したいときに外す
  • 影の濃さは「影の強さ」、境界のぼかしは「影の境界のぼかし」と同じ値を使います
  • Toon マスクの B を黒く塗った所（常に明）には落ち影も出ません
  • Maya では、キャラクターライトと同じ向きの影用のライトを置いて表示します（ビューポートが「全てのライト」+「影」になります。オフにすると元に戻ります）。影の細かい形・ぼけは Unity と少し違うので、最終確認はゲームで

テクスチャの差し替え

ルックタブの テクスチャ（差し替え） で、マテリアルのテクスチャを差し替えます。値は Look に保存され、Unity にも渡ります（元のマテリアルは変わりません）。

項目意味
ベースマップ（色）色のテクスチャ。部位を登録したときに元マテリアルのものが自動で入ります。↺ で元マテリアルのテクスチャに戻ります
法線マップ・強さしわ・凹凸で影の形を細かくします。機能タブで「法線マップ」をオンにすると出ます。Unity と同じ形式（緑 = 上向き、OpenGL 形式）で描いてください
発光マップ・発光色・強さ影やライトに関係なく明るく光らせます（目の光・発光する装飾）。マップの白い所が「発光色 × 強さ」で光ります。マップが無いと面全体が光ります。機能タブで「発光」をオンにすると出ます
  • テクスチャはプロジェクトフォルダの中に置いてください（プロジェクト）。他の PC でも同じ見た目で開けます
  • ペイントツールで描き直したら、ルックタブ上部の テクスチャを読み込み直す を押すと、すぐに反映されます
  • Toon マスク・髪ハイライト・MatCap・顔影マップのテクスチャは、それぞれのグループで差し替えます

Toon マスク（頂点カラーで塗る）

「首の下はいつも影」「頬の線は描かない」のような場所ごとの指定は、モデルの頂点カラーに塗って指定します。塗った瞬間にプレビューに反映されます。

テクスチャで細かく指定する（Toon マスク テクスチャ）

頂点の数が足りず、目の周りの細い影などを頂点カラーで塗り分けられない場合は、ルックタブの マスク › Toon マスク (RGBA) にテクスチャを指定します。ルールは頂点カラーと同じ（白 = 何もしない、R/G/B/A の意味も同じ）で、頂点カラーと掛け合わせて使われます。

スムーズ法線（線が角で割れるとき）

角ばったモデルでは、角のところで線が途切れることがあります。部位タブの下の スムーズ法線を焼く を押すと直ります（対象は表で選んだ部位、選ばなければ選択中のメッシュ）。モデルの形を変えたら焼き直してください。

塗り方（部位タブの下「Toon マスク」）

  1. 部位タブの表で部位を選ぶ（選ばない場合は Maya で選択中のメッシュが対象）
  2. マスク初期化（初回だけ。全体が白 = 何もしない状態で作られます）
  3. 塗りたいチャンネルのボタン R / G / B / A を押す → Maya の Paint Vertex Color Tool が黒で起動します
  4. モデルに塗る（戻したい所は白で塗る）。塗っている最中からプレビューに反映されます
  5. 終わったら 確定（やめる場合は キャンセル）
右の 表示 を「R だけ（白黒）」などにすると、そのチャンネルだけを白黒で確認できます。塗り残しや塗りすぎの確認に便利です。
1 回に塗れるのは 1 チャンネルだけです（R を塗っている間に G を押すと、R を確定してから G に切り替わります）。
ルールは 1 つだけ: 「白 = 何もしない」。効かせたい所を黒く塗る。
塗っていない所・塗り忘れた所はそのまま普通の見た目になるので、失敗しても壊れません。
チャンネル黒く塗ると使い道の例
R（赤）いつも影になる首の下、目の周り、鼻の下、前髪の下、髪の内側
G（緑）線が細くなる・消える頬・鼻・顎の線を消す、毛先の線を細く
B（青）いつも明るくなる顔の真ん中をいつも明るく、鼻の影を消す
A（アルファ）固定色が乗る頬・耳の赤み、口の中を暗く

灰色で塗ると「半分だけ効く」になります。

色の値について

パラメータの色は Unity のインスペクターで見る色と同じ値です。Maya で決めた色を Unity に持っていっても、同じ色に見えます。
