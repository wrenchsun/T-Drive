機能のオン/オフ（機能タブ）

最終更新日: 2026-09-28

リム・髪ハイライト・MatCap などの表現（機能）を、キャラクターごとに使う / 使わないで切り替えます。

  • オフにした機能は「効果なし」で表示され、Unity にも渡りません
  • Unity では、プロジェクトのキャラクターが使う機能だけを入れた専用のシェーダーが作られます。使わない機能を切るほどゲームが軽くなります
  • オフにしても調整した値は消えません。オンに戻すと元の見た目に戻ります

使い方

  1. エディタの 機能 タブを開く
  2. 使う機能の オン にチェックを入れる / 使わない機能のチェックを外す。ビューポートにすぐ反映されます
  3. オフの機能のパラメータは、ルックタブ・キャラクタータブから隠れます（上に「オフの機能は隠しています」と表示）
  4. 調整が終わったら 使っていない機能をオフにする を押すと、値が既定のまま（= 使っていない）機能がまとめてオフになります
間違えてオフにしても Ctrl+Z で戻せます。

表の見方

列意味

使用中● = 値が既定と違う（使っている）。値あり（オフ中） = 調整値が残っているがオフなので効いていない

最初にオンになっている機能

新しい Look では、基本の表現（2 階調影・輪郭線・線のスムーズ法線・頂点カラーの Toon マスク・固定色）だけがオンです。それ以外は必要になったらオンにしてください。

この機能が入る前に作った Look を開いたときは、値を調整していた機能が自動でオンになります（見た目は変わりません）。

注意

  • 機能のオン/オフはキャラクター単位です（A/B のバリアントごとには変えられません）
  • 他のキャラクターが使っている機能は、このキャラクターでオフにしてもプロジェクトのシェーダーには残ります（そのキャラクターでは効果なし）
