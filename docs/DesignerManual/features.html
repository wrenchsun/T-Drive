機能のオン/オフ（機能タブ）

最終更新日: 2026-09-28

リム・髪ハイライト・MatCap などの表現（機能）を、キャラクターごとに使う / 使わないで切り替えます。

  • オフにした機能は「効果なし」で表示され、Unity にも渡りません
  • Unity では、プロジェクトのキャラクターが使う機能だけを入れた専用のシェーダーが作られます。使わない機能を切るほどゲームが軽くなります
  • オフにしても調整した値は消えません。オンに戻すと元の見た目に戻ります

使い方

  1. エディタの 機能 タブを開く
  2. 使う機能の オン にチェックを入れる / 使わない機能のチェックを外す。ビューポートにすぐ反映されます
  3. オフの機能のパラメータは、ルックタブ・キャラクタータブから隠れます（上に「オフの機能は隠しています」と表示）
  4. 調整が終わったら 使っていない機能をオフにする を押すと、値が既定のまま（= 使っていない）機能がまとめてオフになります
間違えてオフにしても Ctrl+Z で戻せます。

部位ごとのオン/オフ（シェーダー単位）

「リムは髪だけ」「セルフシャドウは顔以外」のように、部位・マテリアルごとに機能を切り替えられます。

  1. 機能タブの左の一覧で、部位（またはその中のマテリアル）を選ぶ
  2. 表の 2 列目（見出しが部位名になる）で、機能ごとに 全体に従う / オン / オフ を選ぶ
    • 全体に従う: 「全体」のチェックのとおり（括弧の中が今の状態）
    • オン（緑）/ オフ（橙）: その部位だけ上書き
    • 混在: 部位の中のマテリアルで設定が違う
  3. 上書きのあるマテリアルには、一覧で ✎ が付きます
  • 切り替えられるのは、マテリアルの値で効く機能（リム・髪ハイライト・MatCap・セルフシャドウ・法線マップ・発光・2 影 など）です。接地影・画面上の線・ライトの安定化などは「キャラクター単位」で、全体でだけ切り替えます
  • ルックタブでは、選んだ部位でオフの機能の欄が隠れます
  • Unity では、使う機能の組み合わせごとに専用のシェーダーが作られます（髪用・目用 など）。使わない部位からは機能ごと取り除かれるので軽くなります
  • Ctrl+Z で戻せます

表の見方

列意味
全体キャラクター全体のオン/オフ。「2 階調影」は必須なので外せません
（選んだ部位）その部位だけの上書き（部位ごとのオン/オフ）。「キャラクター単位」の機能は部位ごとには切り替えられません
Unity での実現シェーダー / メッシュ / コンポーネント / Renderer Feature（画面効果）のどれで作るか
Maya プレビュー○ = Maya でも同じ見た目、△ = 簡易表示（Unity で最終確認）、× = Maya では確認できない
使用中● = 値が既定と違う（使っている）。値あり（オフ中） = 調整値が残っているがオフなので効いていない

最初にオンになっている機能

新しい Look では、基本の表現（2 階調影・輪郭線・線のスムーズ法線・頂点カラーの Toon マスク・固定色）だけがオンです。それ以外は必要になったらオンにしてください。

この機能が入る前に作った Look を開いたときは、値を調整していた機能が自動でオンになります（見た目は変わりません）。

注意

  • 機能のオン/オフ（全体・部位ごと）は A/B のバリアントごとには変えられません
  • 他のキャラクターが使っている機能は、このキャラクターでオフにしてもプロジェクトのシェーダーには残ります（そのキャラクターでは効果なし）
