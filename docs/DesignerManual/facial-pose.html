ポーズタブ

最終更新日: 2026-10-05

グリッドで選んだ1 つの点の補正ポーズを作る場所です。ポーズは「シェイプの重み」と「ボーンのずれ」でできています。

1 点のポーズを作る手順

  1. グリッドタブで、作りたい角度の点をクリックします。カメラがその角度へ動き、編集が始まります（上に「編集中: レイヤー「Neutral」 点 R1, C3 …」と出ます）
  2. 顔の形を直します。やり方は 3 通りで、混ぜて使えます
    • スライダー — このタブのシェイプ欄のスライダーや数値を動かす
    • Maya の標準の道具 — Shape Editor やチャンネルボックスでシェイプを動かす
    • ボーン — 目などのジョイントを Maya の移動 / 回転ツールで動かす
  3. Maya 側で動かしたときは、シーンから取り込む を押します。動かした値が、編集中のポーズに入ります
  4. 保存（この点をキーにする） を押します。点が緑（キー）になります
  5. グリッドでベイクします
保存するまで、データは変わりません。保存せずに別の点へ移ろうとすると、保存 / 破棄 / キャンセルを聞かれます（レイヤーを切り替えるときも同じです）。全部 0 のポーズを保存すると、その点は消えます。

シェイプの種類ごとのタブ

シェイプの一覧の上に、種類ごとのタブが出ます。シェイプの数が多いキャラクターでも、目・口などの部位からすぐに探せます。

  • すべて — 全部のシェイプ。目 / 眉 / 口 … — 命名規則プロファイルに沿って、名前で分けたもの（shizuku なら 目 / 眉 / 口 / あご / 頬 / 視線 / リップシンク / ハイライト / その他の表現 / 体の調整）。値あり — このポーズで値が入っているもの（土台の表情の値があるものを含む）
  • かっこの中の数字は、その種類のシェイプの数です。編集中の値があるタブには ● が付きます
  • 絞り込みの欄は、選んでいるタブの中で効きます。タブが多いときは、右端の矢印で送れます
  • プロファイルが無い・種類の決まりが無いときは、名前の先頭（eye_ など）で自動で分けます。うまく分かれないときは「すべて」だけになります
  • セットアップタブの作業セットの一覧でも、同じ種類で絞り込めます（「表示中を全部オン / オフ」は、選んでいる種類にだけ効きます）

ボタン

ボタンはたらき
保存（この点をキーにする）編集中のポーズをこの点に保存します
読み直す編集中の値を捨てて、保存してあるポーズを読み直します
ゼロに戻すシェイプもボーンも全部 0（元の姿勢）にします。保存するまでデータは変わりません
左右反転編集中のポーズの左右を入れ替えます（_L と _R、ボーンのずれも鏡映）
この点を書き出し…編集中のポーズを、単独のポーズファイル（.fcpose.json）に書き出します。全部 0 のポーズは書き出されません
読み込み…ポーズファイルを編集中の値へ読み込みます。保存するまでデータは変わりません。ポーズを別のキャラクターへ持っていくときに使います
アニメから読み込む…Maya のアニメの今のフレーム、または Unity の .anim の値を、編集中のポーズへ読み込みます（詳しくは下）
シーンから取り込むMaya の Shape Editor・チャンネルボックス・回転 / 移動ツールで動かした値を取り込みます（土台の表情があるときは、ポーズの部分だけ）。作業セットだけにチェックすると、作業セットのものだけが対象です。編集中のときだけ使えます

アニメから読み込む

アニメの表情を、編集中のポーズに取り込めます。「この表情のときの補正を作りたい」ときに便利です。ポーズタブの「アニメから読み込む」の箱の アニメから読み込む… を押します。

項目意味
今のフレーム（Maya のシーンのアニメ）Maya のシーンのシェイプ・ボーンについているアニメの、今のタイムラインのフレームの値を読みます
Unity の .anim ファイルUnity のアニメーションクリップを読みます。ファイルを選び、時刻（秒）でクリップのどこを読むかを決めます（1 コマだけのクリップは 0 のまま）
作業セットだけ作業セットのシェイプ・ボーンだけを読みます（作業セットが空なら全部）
ボーンも読む目などのボーンの動きも、基準姿勢からのずれとして読みます。切るとシェイプだけ
置き換え / 足す置き換え = 編集中の値をいったん捨てて、アニメの値にする。足す = アニメが動かしているものだけを上書きし、ほかの編集中の値は残す
  • モデルに無い名前（シェイプ・ボーン）は読まれません。読めなかった名前は一覧で知らされます（下の状態表示にカーソルを合わせると見られます）
  • 保存していない編集中のポーズを「置き換え」で上書きするときは、確認が出ます
  • 保存するまで、点のデータは変わりません。読み込んだあと、保存（この点をキーにする） を押して初めて点に入ります

土台の表情

「笑っているときの補正」を作るときに、笑顔の上に補正だけを足した形で確認したい、というときの機能です。表情のアニメ（Unity の .anim）を土台としてシーンに当てます。

  1. 編集を始めます（グリッドで点を選ぶ）
  2. 「土台の表情」の 選ぶ… を押し、表情の .anim ファイルと時刻を選んで 当てる を押します
  3. 顔が土台の表情になります。そのうえでポーズを作ります
  4. 終わったら 外す を押します

土台はポーズに「足されて」見えます

ゲームでは、表情のアニメと補正が足し算で効きます。Maya の土台の表情も、それと同じにポーズの値へ足されてシーンに当たります。

  • スライダーに出るのは、ポーズ自身の値だけです
  • 土台が効いているシェイプの行には、横に小さく 「+0.60（土台）」のように、土台ぶんの値が出ます。見た目の形は「スライダーの値 + 土台」です
  • 足した合計が、そのシェイプの動かせる範囲を超えると、その行が警告の色になります（ゲームでも範囲を超えた値になる、という知らせです）
  • 「シーンから取り込む」では、ポーズの部分だけが取り込まれます（土台ぶんは引いて取り込みます）。土台の値がポーズに混ざることはありません

土台が残らない場所

  • 土台はシーンに当てるだけの確認用です。保存するデータ・ベイク・Unity への出力には入りません
  • 点を切り替えても、土台は残ります
  • 外す を押すか、編集を終えると消えます。エディタを閉じたときも外れます
  • 土台に使えるのはシェイプだけです（ボーンの動きは土台に入りません）

シェイプ欄

  • 作業セットのシェイプが、スライダーと数値で並びます。0 のボタンでそのシェイプを 0 に戻せます
  • 動かせる範囲はプロファイルで決まります（ツールチップに「範囲 0 〜 1」と出ます）。範囲を超える値は丸められます
  • 上の「絞り込み」で名前の一部を入れると探せます。「作業セットだけ」を外すと、作業セット以外も出ます
  • 0 でない行は、黄色の太字になります。「編集した値: ○ 本」で数が分かります

ボーン欄

目などのジョイントの基準姿勢からのずれを、数値で見られます。数値は親のボーンから見た移動（cm）と回転（度）です。

  • 移動 cm の X・Y・Z、回転 ° の X・Y・Z。回転は Maya の回転順 XYZ と同じです。回転 Y は ±90° までです
  • 行の左の丸でボーンを選び、選んだボーンを Maya で選択 を押すと、Maya でそのジョイントが選ばれます。移動 / 回転ツールで動かしたら、シーンから取り込む を押してください
  • このボーンを戻す（または行の「戻す」）で 1 本、ボーンを全部戻す で全部を元へ戻します（シェイプは触りません）
  • ボーンが多いときは、60 本までを表示します。残りは「絞り込み」で探してください
スケール（拡大縮小）の欄はありません。ボーンの補正は移動と回転だけです。
