ポーズタブ

最終更新日: 2026-10-03

グリッドで選んだ1 つの点の補正ポーズを作る場所です。ポーズは「シェイプの重み」と「ボーンのずれ」でできています。

1 点のポーズを作る手順

  1. グリッドタブで、作りたい角度の点をクリックします。カメラがその角度へ動き、編集が始まります（上に「編集中: レイヤー「Neutral」 点 R1, C3 …」と出ます）
  2. 顔の形を直します。やり方は 3 通りで、混ぜて使えます
    • スライダー — このタブのシェイプ欄のスライダーや数値を動かす
    • Maya の標準の道具 — Shape Editor やチャンネルボックスでシェイプを動かす
    • ボーン — 目などのジョイントを Maya の移動 / 回転ツールで動かす
  3. Maya 側で動かしたときは、シーンから取り込む を押します。動かした値が、編集中のポーズに入ります
  4. 保存（この点をキーにする） を押します。点が緑（キー）になります
  5. グリッドでベイクします
保存するまで、データは変わりません。保存せずに別の点へ移ろうとすると、保存 / 破棄 / キャンセルを聞かれます（レイヤーを切り替えるときも同じです）。全部 0 のポーズを保存すると、その点は消えます。

ボタン

ボタンはたらき
保存（この点をキーにする）編集中のポーズをこの点に保存します
読み直す編集中の値を捨てて、保存してあるポーズを読み直します
ゼロに戻すシェイプもボーンも全部 0（元の姿勢）にします。保存するまでデータは変わりません
左右反転編集中のポーズの左右を入れ替えます（_L と _R、ボーンのずれも鏡映）
この点を書き出し…編集中のポーズを、単独のポーズファイル（.fcpose.json）に書き出します。全部 0 のポーズは書き出されません
読み込み…ポーズファイルを編集中の値へ読み込みます。保存するまでデータは変わりません。ポーズを別のキャラクターへ持っていくときに使います
シーンから取り込むMaya の Shape Editor・チャンネルボックス・回転 / 移動ツールで動かした値を取り込みます。作業セットだけにチェックすると、作業セットのものだけが対象です。編集中のときだけ使えます

シェイプ欄

  • 作業セットのシェイプが、スライダーと数値で並びます。0 のボタンでそのシェイプを 0 に戻せます
  • 動かせる範囲はプロファイルで決まります（ツールチップに「範囲 0 〜 1」と出ます）。範囲を超える値は丸められます
  • 上の「絞り込み」で名前の一部を入れると探せます。「作業セットだけ」を外すと、作業セット以外も出ます
  • 0 でない行は、黄色の太字になります。「編集した値: ○ 本」で数が分かります

ボーン欄

目などのジョイントの基準姿勢からのずれを、数値で見られます。数値は親のボーンから見た移動（cm）と回転（度）です。

  • 移動 cm の X・Y・Z、回転 ° の X・Y・Z。回転は Maya の回転順 XYZ と同じです。回転 Y は ±90° までです
  • 行の左の丸でボーンを選び、選んだボーンを Maya で選択 を押すと、Maya でそのジョイントが選ばれます。移動 / 回転ツールで動かしたら、シーンから取り込む を押してください
  • このボーンを戻す（または行の「戻す」）で 1 本、ボーンを全部戻す で全部を元へ戻します（シェイプは触りません）
  • ボーンが多いときは、60 本までを表示します。残りは「絞り込み」で探してください
スケール（拡大縮小）の欄はありません。ボーンの補正は移動と回転だけです。
