シェイプタブ

最終更新日: 2026-10-03

顔のシェイプ（ブレンドシェイプ）を作る・直す・整える作業を助ける道具が集まったタブです。Maya のスカルプトツールで直接彫ったり、左右対称にしたり、別のメッシュへ写したりできます。

確認中: 道具の動きは、テスト用の小さなモデルで確かめてあります。実際のスカルプトツールでの彫りやすさ、実際のキャラクターでの左右対称・写した結果の品質は、まだ人の目で確認できていません。気づいたことは開発者に伝えてください。
どの道具にも共通のルール
  • 元からあるシェイプは、確認なしでは変えません。上書きや変更が必要なときは、先に「よろしいですか」と聞きます
  • どの操作も、Maya の Ctrl+Z を 1 回押すと元に戻ります
  • このタブから消せるのは、名前が fcs_ か FC_ で始まるものだけです。元からあるシェイプは消えません

対象のシェイプ（一覧）

いちばん上の一覧には、顔のメッシュのシェイプが並びます。下の道具は、ここで選んだシェイプに対して働きます（複数選べます）。名前の絞り込みと、右のプルダウン（すべて / 元から / FC_ / fcs_ / 組み合わせ / 作ったもの）で探せます。

各行の ［ ］の中の言葉は、そのシェイプがどこから来たかを表します。

表示意味
［元から］モデルにもともとあったシェイプ。守られていて、確認なしでは変わりません
［FC_］ベイクでできた補正用のシェイプ。ツールが作り直すもの
［fcs_］「この角度で彫る」でできた、その点専用のシェイプ（彫り用）。Unity へは出ません
［作ったもの］このタブの道具で新しく作ったシェイプ（左右に分けたもの・ポーズから作ったもの・_Ex など）
［組み合わせ］2 本のシェイプを同時に上げたときだけ効く補正（fcs_combo_…）

行の最後に「空」（中身が動いていない）・「中間 0.5」（中間形がある）・「駆動」（組み合わせ補正が他のシェイプに駆動される）と出ることがあります。

この角度で彫る

こんなとき: 横顔の口元など、ある角度だけ形を直接彫って直したいとき。

グリッドで選んだ点のポーズを当てた状態で、その点専用のシェイプ（fcs_…）を Maya のスカルプトツールや移動ツールで彫ります。彫った形は点のポーズに記録され、ベイクに含まれます。

  1. グリッドタブで、彫りたい角度の点を選びます
  2. シェイプタブの この角度で彫る を押します（「選択中の点の彫り用シェイプ: …」と出ていれば押せます）。画面に「彫り中: …」と出ます
  3. Maya のスカルプトツール（または移動ツール）で、顔のメッシュを彫ります
  4. 彫り終わったら 彫り終わる を押します。彫った形がその点のポーズに記録され、保存されます
  5. グリッドでベイクします。プレビューで、その角度のときだけ彫った形が出ます
  • 彫った形は、その点専用のシェイプ fcs_… に入ります。Unity へは出ません（ベイクの結果に含まれるので、補正としては Unity でも効きます）
  • やり直したいときは、彫りを消す で fcs_ のシェイプを消せます（ポーズからの参照も外れます）。Ctrl+Z でも戻せます
  • 下の一覧に、fcs_ のシェイプと、それがどの点のものかが出ます。どの点からも使われていないもの（孤立）は「孤立」と出ます
頭を動かしたポーズの点では使えません。彫る形は頭のボーンが基準姿勢のときの形で作るため、頭が動いていると結果がずれるからです。理由が画面に出て、彫りは始まりません。頭は基準姿勢のままにしてください（目や口のボーンのずらしは使えます）。

ポーズをシェイプにする

こんなとき: よく使う組み合わせ（口を少し開けて、口角を上げる、など）を、1 本のスライダーにまとめたいとき。

  1. ポーズタブで、スライダーやボーンを動かして形を作ります
  2. シェイプタブの「名前」を決めます（初期値は pose_shape_01）
  3. 必要なら 作業セットに入れる（初期はオン）と、シーンの今の状態を取り込んでから作る（Maya 側で動かしたとき）にチェックします
  4. ポーズをシェイプにする を押します

今のポーズが、新しいシェイプ 1 本になります。元のシェイプは上書きしません。

左右に分ける

こんなとき: 左右がつながった 1 本のシェイプ（例: smile）を、左右別々に動かせるようにしたいとき。

  1. 一覧で、分けたいシェイプを 1 本選びます
  2. 「左の名前」「右の名前」を確かめます（選ぶと自動で入ります）
  3. 中央のぼかし幅 を決めます。中央のつなぎ目をなめらかにする幅です。0 にすると段差になります
  4. 左右に分ける を押します

左（_L）と右（_R）の 2 本ができ、2 本を両方上げると元の形になります。元のシェイプは残ります。顔の左右は、メッシュの X の向きで決まります（+X が左）。

ミラー

こんなとき: 左側（_L）だけ直したので、右側（_R）を同じ形にしたいとき（逆も同じ）。

  1. 直したほうのシェイプを 1 本選びます
  2. ミラー（反対側を作る / 更新） を押します

反対側のシェイプが作られる（すでにあれば更新される）ので、左右対称になります。

  • 「ミラーの許容誤差」は、左右の頂点が「鏡の位置にある」とみなす差の大きさです。普通は初期値のままで構いません
  • 左右で位置が合わない頂点があると、その頂点を選択して止まります。「それでも続けますか」と聞かれます。続けると、合わない頂点は 0 のまま（動かない）になります。やめたときは、選択された頂点をビューポートで見て直してください

中間形・誇張形

ボタンはたらき
中間形を足す「重み」で決めた値（0.01〜0.99）のときの形として、今のシーンの形を足します。例えば重み 0.5 のとき、スライダー 0.5 でこの形になります。選んだシェイプが元からあるものなら、確認が出ます
誇張形 _Ex を作る選んだシェイプを 1 にした形に足す分を <名前>_Ex として作り、動かせる範囲を 0〜2 に広げます。誇張の評価（ゲームでの効かせ方）は 準備中です

組み合わせ補正

こんなとき: 「口角を上げる」と「眉を上げる」を同時に使ったときだけ、形が崩れるのを直したいとき。

  1. 一覧で、シェイプを 2 本選びます
  2. 組み合わせ補正を作る（2 本選択） を押します。fcs_combo_… というシェイプができます（［組み合わせ］）
  3. できた組み合わせ補正を一覧で選び、組み合わせ補正を彫る を押します。2 本を上げた状態になるので、スカルプトツールで形を直します
  4. 終わったら、「この角度で彫る」のところにある 彫り終わる を押します
  • この補正はMaya の中だけで効き、ベイクには含まれます。Unity へは fcs_ のシェイプとしては出ません

別メッシュへ写す

こんなとき: 顔のシェイプを、まつ毛・眉・別の頭など、別のメッシュにも作りたいとき。

  1. 一覧で、写したいシェイプを選びます（複数可）
  2. 「別メッシュへ写す」の右のプルダウンで、写し先のメッシュを選びます
  3. 写す を押します

頂点の並びが同じなら、そのまま複写します。違うときは、近くの頂点を目安に転写します。写し先の元からあるシェイプは、確認なしでは上書きしません。

整理

ボタンはたらき
微小な差分を掃除選んだシェイプのうち、「しきい値」より小さい動きを 0 にします。元からあるシェイプは、確認が出ます
空・未使用を調べる空のシェイプ、どのポーズ・作業セットからも使われていないシェイプ、孤立した fcs_ / FC_、命名規則プロファイルの標準シェイプの不足を、下の欄に出します（見るだけで、何も変わりません）
孤立した fcs_ / FC_ を消すどの点からも使われていない fcs_ と、格子に対応しない FC_ を消します。確認が出ます
検証タブへ（改名の候補）プロファイルに沿った一括改名は、検証タブで行います
