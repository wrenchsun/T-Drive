リップシンクの対応表

最終更新日: 2026-10-04

しゃべっているときの口の形を決める対応表を作ります。音声の解析は T-Drive では行いません。別のツール（uLipSync など）が出す「音素の強さ・声量」を受け取り、この表に従って口のシェイプを動かします。

Maya では表を作って「試す」で確かめるところまでです。実際の音声に合わせて動くのは Unity です（Unity での使い方）。実際のキャラクターと音声での確認は 確認中 です。

作り方

  1. FacialController のリップシンクタブを開き、「リップシンクを使う」を押します
  2. 「プロファイルから作る」を押すと、命名規則プロファイルに合わせて音素と基本の行が入ります（shizuku なら A / I / U / E / O、VRChat のビセム、ARKit）。結果（作った行・残した行・見つからなかったシェイプ）が表示されます。プロファイルが無いとき・合わないときは、「音素」の欄で自分で足します
  3. 対応表のマスを押すと、そのマスが編集の対象になります。ポーズタブのスライダーで口の形を作り、「保存（この口の形にする）」を押します。保存されるのはシェイプの値だけで、ボーンは保存されません
  4. 感情ごとに口の形を変えたいときは、感情の列のマスにも形を作ります（例: Joy のときの「あ」は口角を上げる）。空のマス「（基本）」は、基本の行がそのまま使われます
  5. 「試す」で確かめます

各項目

項目意味
使うオフにすると、Unity でリップシンクが働きません（表は残ります）
全体の強さ口の動き全体の倍率（0〜1）
声量（最小 / 最大 / から / まで）声の大きさで口の開きを変えます。声量が「最小」のとき口の大きさは「から」倍、「最大」のとき「まで」倍になり、間はなめらかにつながります。声量が渡されないときは「まで」倍です
追従の速さ口が目標の形へ追いつく速さ。Unity だけで使います（0 = すぐに追いつく）
音素（足す / 名前を変える… / 削除… / 上へ / 下へ）音素の名前は自由です。解析ツールが出す音素の名前と同じにしてください（違うときは Unity のつなぎの部品で対応を書けます）。削除すると、その音素の行も消えます
対応表行 = 音素、列 = 基本と感情（レイヤー）。「2 シェイプ」= 形が入っている / 「—」= 基本の行が無い / 「（基本）」= 感情の行が無いので基本を使う / ⚠ = 無いシェイプを指しているなど（検証タブに出ます）
このマスを空にする選んだマスの形を消します（右クリックでも）

試す

「試しはじめる」を押し、音素ごとのスライダー・声量・感情の重みを動かすと、計算した口の形がシーンに当たります。データは変わりません。「試すのをやめる」・ほかの対象を選ぶ・タブを離れる・編集を終える、で元に戻ります。

  • 複数の音素を同時に上げると、形が足し合わされます（合計が 1 を超えると、可動域で止まります）
  • 感情の重みは、表にその感情の行がある感情だけ出ます
  • 追従の速さは Maya の「試す」には効きません

しくみ（知っておくとよいこと）

  • しゃべっていないときは、アニメーションの口のままです。しゃべると、その強さに応じて対応表の口に置き換わります
  • リップシンクで口が開くと、角度の補正の「表情が強いときに補正を弱める」が効きます
  • ベイクは要りません（元のシェイプを直接動かします）。表は .fcpose に入って Unity へ渡ります

Unity での使い方

  • Runner のインスペクターに「リップシンク」の状態（今の音素の強さ・声量）が出ます。プレビューをオンにすると、音素ごとのスライダーで口の動きを確かめられます（「口を戻す」で元に戻ります）
  • 調整 › リップシンクの強さ / 追従の速さ で、取り込んだデータを変えずに調整できます
  • 音声の解析とのつなぎ: uLipSync（無料・MIT ライセンス）を使う場合、プロジェクトに uLipSync を入れると、部品「T-Drive › Facial uLipSync Bridge」が使えるようになります。uLipSync と同じオブジェクトに付けるだけです。音素の名前が違うときは、部品の対応表に書きます。プログラマーがほかの解析をつなぐときは Runner.SetLipSync(...) に音素の強さと声量を渡します
  • キャラクターを無効にする・片付ける・シーンを保存するとき、口のシェイプは書く前の値に戻ります
