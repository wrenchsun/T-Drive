出力と Unity

最終更新日: 2026-10-04

Maya で作った補正を Unity に渡し、ゲームの中で動かすまでの手順です。

確認中: Unity 側の部品は動作テストを通っていますが、Maya が出力した実際のファイルを Unity に置いての通し確認は、まだ終わっていません。うまくいかないときは困ったときを見て、状況を開発者に伝えてください。

出力タブ（Maya）

項目内容
Unity 向けに出力FBX と補正データ（.fcpose）を書き出します。別のプロセスで書くので、Maya の画面は止まりません（「書き出し中… ○ 秒」と出ます）。中止・フォルダを開くもあります。開いているシーンは変わりません
UE 版向けに出力…補正データを .fcpose.json のまま書き出します（Unreal Engine 版の FacialController 用）
Timeline 用に出力（.fctrack）プレビューの強さ・感情・手動角度に打ったキーを、ショットごとのファイル（<ショット名>__<モデル名>.fctrack）にします。置いたあとの流れは下の説明。プレビューの「誇張」にキーを打ってあれば、その動きも入ります

出力の前に自動で検証が走り、エラー・未ベイク・ベイク後の変更があれば、それでも出力する / やめるを聞かれます。出力前に検証タブで直しておくのがおすすめです。

出力されるファイル

プロジェクトフォルダの facial\<キャラクター>\export\unity\ に、次の 2 つができます。

ファイル内容
<キャラクター>.fbx顔のメッシュと同じ骨格のモデル。ブレンドシェイプに、焼いた FC_ のシェイプが入ります（彫り用の fcs_ のシェイプと作業用のノードは入りません）
<キャラクター>.fcpose補正データ（格子・ポーズ・感情レイヤー・方針）

結果の欄に、メッシュの数・FBX に入った FC_ の数・除いた fcs_ の数・警告が出ます。

Unity での使い方

  1. 2 つのファイルを Unity のプロジェクトに置く（Assets の中）。.fcpose を置くと、補正のデータ（FacialCorrectionData）が自動でできます。FBX の Blend Shape Normals は Import にしてください（検証で確認できます）
  2. キャラクターの Prefab（またはシーンのオブジェクト）に Facial Correction Runner を付けます（Add Component › T-Drive › Facial Correction Runner）
  3. Runner の データの欄に、できたデータを入れます。対象のメッシュと基準ボーンは、空なら名前から自動で探します
  4. 再生すると、ゲーム中のカメラ（既定はメインカメラ）の角度に合わせて補正が掛かります。再生しなくても、Runner のプレビューで確認できます

Runner のインスペクター

欄内容
プレビュー再生しなくても、Scene ビューのカメラの角度で補正を掛けて確認します。プレビュー: オン / オフ、補正あり / 補正なし（比べる）、視点（Scene ビューのカメラ / ターンテーブル / 角度を指定）、格子ビューアを開く。オフにする・保存する・再生に入ると元の値に戻り、シーンは変更されません
データと対象データ・調整用アセット・対象メッシュ・基準ボーンなどの設定
状態見つかったシェイプの数・足りないシェイプ・今の Yaw / Pitch・倍率（表情 × 距離 × 強さ）・今の重み。足りないシェイプがあるときは、Maya で出力し直します
調整（簡単なパラメータ）下の「調整できる値」。調整用アセットがあれば、値を上書きして保存できます
感情の重み感情レイヤーごとの重み（0〜1）とミュート（オンで 0 として扱う）
視点補正の角度を決める視点（空ならメインカメラ）。手動の角度を使うをオンにすると、Yaw / Pitch を直接指定できます
マテリアル出力（任意）マテリアルへ角度・感情の重みを渡します。使わなければそのままで構いません
検証エラー / 警告 / 情報の件数と内容。シェイプの過不足・基準ボーン・取り込み設定などを確認します。「もう一度検証する」で取り直し。「可動域の指定のうち ○ 件は FC_ 以外のシェイプ向けのため Unity では使われません」という警告は、件数が多くても1 件にまとまって出ます（Unity は FC_ のシェイプだけを動かすため、故障ではありません）
ボタンFC_* を 0 に戻す / キャッシュを作り直す（メッシュやボーンを変えたとき）/ Maya へ戻す JSON を書き出す…

調整用アセット

Runner の「調整」で調整用アセットを作る…を押して保存場所を決めると、値を変えて保存できます。取り込んだデータは変わらず、.fcpose を取り込み直しても調整は残ります。「上書き」にチェックを入れた行だけが使われます。Ctrl+Z で戻せます。

グリッドのウィンドウ

メニュー Tools › T-Drive › Facial › グリッド で開きます。Runner（またはデータ）を選ぶと、Maya のグリッドタブと同じ向き（上がふかん・左が −Yaw）で格子を表示します。緑 = キー / 水色 = 自動生成 / 灰 = 無し / 赤い枠 = メッシュに FC_ のシェイプが無い / 赤い点 = 今の角度。点をクリックすると、Scene ビューのカメラがその角度へ動き、プレビューが始まります。「固定」で表示対象を固定、「プレビュー」でオン / オフ、レイヤーも切り替えられます。

操作は Maya のグリッドタブと同じです。

  • マスをクリック — その点を選び、Scene ビューのカメラがその角度へ動きます（顔との距離は保ちます）。プレビューが始まります。「カメラも動かす」をオフにすると、選ぶだけでカメラは動きません
  • 赤い点 — いまの Scene ビューのカメラの向きです。カメラを回すと付いて動きます。範囲の外では端に張り付いて「範囲外」と出ます
  • 赤い点をドラッグ（または Shift を押しながらドラッグ）— カメラを好きな角度へ動かせます。マスとマスの間の見え方を確かめられます。Shift + クリックで、その角度へ一度に移動します。ドラッグでは点を選びません
  • 右上に「カメラ: Scene ビュー Yaw 37.5° / Pitch -10.0°」と、いまの角度が出ます
  • 色: 緑 = キー / 水色 = 自動生成 / 灰 = 空 / 橙の枠 = 選択中 / 赤い枠 = メッシュにその補正のシェイプが無い
  • Scene ビューが正投影（または 2D）のときは、ドラッグでカメラを動かせません。透視に切り替えてください

Maya へ戻す JSON

Unity で調整した値を Maya に持ち帰りたいときは、Maya へ戻す JSON を書き出す…を使います。強さ・追従などの値が JSON に出ます。端のフェードも、Unity で「上書き」にしているときは JSON に入ります（上書きしていないときは入りません。そのときは Maya のセットアップタブの値が使われます）。

Timeline で補正を動かす

確認中: Timeline のトラックは実装済みで、時刻を指定して値を調べるテストは通っています。ただし、実際のカットシーンで人が操作して確かめることは、まだ終わっていません（Timeline ウィンドウの操作感、再生中のシーク・スキップ・一時停止での挙動など）。うまくいかないときは開発者に伝えてください。

カットシーンの演出で、補正の強さや感情の重み、角度を時間に沿って変えられます。Timeline に 「Facial Correction」のトラックを足し、その上にクリップ 「補正」を置きます。トラックは、キャラクターの Animator に結びます（キャラクターの子に Runner があれば、それが使われます）。

クリップ「補正」の項目

項目意味
強さを使う / 強さ（0〜1）オンにすると、このクリップの間、補正全体の強さを弱める・切る。0 で補正なし
感情の重み感情レイヤーの名前と重みの組。書いていないレイヤーは Runner の値のまま。名前は、補正データのレイヤー名と同じ綴りにします（大文字・小文字も区別します）
角度を固定する / Yaw / Pitchオンにすると、カメラの位置に関係なく、ここで決めた角度で補正します（決め構図用）。Yaw はキャラクターの正面が 0 で、カメラがキャラクターから見て左にあると正。Pitch はカメラが上（ふかん）で正
視点補正の基準にするカメラなど。空なら、Runner の設定（なければメインカメラ）に従います
カット補正（ポーズ / ポーズの重み）このクリップの間だけ、1 点のポーズ（.fcpose から取り込んだもの）を足します。ショットごとの手直し用です。元のデータは変わらず、クリップが終わると元に戻ります
コマ打ち（コマ打ちを使う / fps）オンにすると、このクリップの間だけ補正の更新をこの fps に間引きます（0 = 毎フレーム）。更新の間は前の重みのまま止まります
誇張（誇張を使う / 0〜1）オンにすると、このクリップの間だけ誇張用シェイプ（FC_…_Ex）の強さを変えます。オフのときは、.fctrack に入っている誇張の動き（Maya で打ったキー）に従います。1 = 作った通り、0 = 誇張なし。誇張用シェイプの無いキャラクターでは変わりません
パース補正（パース補正を使う / 強さ 0〜1）オンにすると、このクリップの間だけパース補正の強さを変えます。1 = 作った通り、0 = 補正なし。オフのときは、.fctrack に入っているパース補正の動きに従います
  • クリップが重なっている所は、なめらかにブレンドされます
  • クリップの外では、通常の補正（Runner の設定どおり）に戻ります
  • 再生していなくても、Timeline ウィンドウでスクラブ（時間を動かす）すると、補正の変化が見えます。プレビューをやめると、シェイプとボーンは元の値に戻ります
  • Maya で打ったキーを Timeline に取り込む（.fctrack）: Maya の出力タブで書き出した <ショット>__<モデル>.fctrack を、D-Drive のカットシーンの置き場所（Assets/SourceAssets/Cutscene/<分類>/）に置くと、そのカットシーンの Timeline に「<モデル>_Facial(auto)」というトラックが自動で入り、強さ・感情の重み・角度の固定が Maya のキーどおりに動きます。D-Drive 1.4.0 以降では、FBX と .fctrack をどちらの順で置いても入ります。それより前の D-Drive では、先に同じショットの FBX を取り込んでおいてください。置き直すと「(auto)」のトラックだけが更新され、手で足したトラックやクリップは残ります。クリップに手で入れた値は、取り込んだキーより優先されます。反映されないときは、.fctrack を選んで Tools › T-Drive › Facial › .fctrack を Timeline に反映し直す を実行します。実際のカットシーンでの確認はこれから（確認中）です
  • D-Drive のプールで使うキャラクター: モデルの Prefab に「Facial Model Instance Bridge」も付けてください（Runner のインスペクターのボタンで追加できます）。出し直したキャラクターにも補正が正しく掛かります。この部品は D-Drive 1.4.0 以降で使えます（タグが出るまでは、プログラマーが Project Settings › Player › Scripting Define Symbols に TDRIVE_DDRIVE_FC_FORCE を足します）
  • 一時停止中も、クリップの指定（強さ・感情・角度の固定・カット補正）はそのまま保たれます。カットシーンが終わるか、キャラクターが片付けられると外れます
  • 1 体に Facial トラックを 2 本以上置くと、合わさります。強さは掛け合わせ、感情・誇張・コマ打ちは手で置いたトラックが「(auto)」より優先、カット補正は全部足されます
  • 再生していないときの Timeline のプレビューは、メインカメラがあればそのカメラから見た角度で補正します。シーンビューのカメラに従わせたいときは、Runner の プレビュー ›「編集時の視点」を変えます
  • プレビュー中は、シーンに「変更あり」の印が付きます。保存しても、補正のシェイプの重みは 0 で保存されます

D-Drive のカットシーンで使うとき

D-Drive のカットシーンに Facial Correction のトラックを足すときは、トラックを正しいキャラクターに結ぶのが大事です。方法は 2 つあります。

  1. 基本: Binding の Target を「SameAsTrack」にする — カットシーンの Bindings に Facial のトラックを足し、Target を SameAsTrack にして、キャラクターのアニメーショントラックと同じ相手を指定します。これで、2 つのトラックが同じキャラクターに結ばれます
  2. トラック名で自動的に結ぶ — トラックの名前を 「<役名>_Facial」にします（例: 役名が Hero なら Hero_Facial）。Binding を書かなくても、同じ役名のキャラクターのアニメーショントラックと同じ相手に結ばれます

D-Drive の検証（カットシーンの検証）で、Facial のトラックに問題があると、次のコードが出ます。

コード意味直し方
TD-FACIAL-001トラックの結び先が分かりません（このトラックは何もしません）Bindings にトラック名を足す。または、トラック名を「<役名>_Facial」にして、同じ役名のアニメーショントラックと、その Binding を置く
TD-FACIAL-002クリップの感情レイヤー名が、モデルの補正データに無い（その重みは無視されます）綴りを補正データのレイヤー名に合わせる
TD-FACIAL-003クリップのカット補正のポーズが見つからない（エラー）ポーズの参照を入れ直す
TD-FACIAL-004結び先のキャラクター（Prefab）に Facial Correction Runner が付いていないPrefab に Runner を付ける
TD-FACIAL-005結び先の Runner に、補正のデータが入っていないRunner の「データ」に補正データを入れる

デバッグ表示

実行中に、補正がどう掛かっているかを画面で確認できます。キャラクターに Add Component › T-Drive › Facial Debug Overlay（メニュー名は「T-Drive/Facial Debug Overlay」）を付け、レベルを選びます。

レベル表示
0切（何も出ません）
1画面に HUD。今の Yaw・Pitch、スナップ（カット切り替えとみなして即時反映したか）、倍率、効いているシェイプの重みの上位
2HUD + Scene ビューの 3D 表示。頭の前方向（青）・視点への向き（黄）・格子の中心（水色）

表示する Runner・重みの件数・HUD の位置も変えられます。確認中: 見た目は、まだ人の目で確認できていません。

調整できる値

項目意味
全体の強さ補正全体の強さ（0〜1）。0 で補正なし
追従の速さ重みが目標へ追いつく速さ。大きいほど速い。0 以下 = 即時
スナップの角度（度）視点がこの角度より大きく飛んだら、カット切り替えとみなして即時に反映します
距離フェード 開始 / 終了（m）視点が遠くなると補正が弱まり始める距離 / 補正が 0 になる距離。開始 = 終了 = 0 で無効
表情での弱め具合表情が強いとき補正を弱める度合い（0〜1）。0 = 弱めない
端のフェード（度）格子の範囲の外側で、補正が 0 へ消えていく幅
シャープさ1 = そのまま。大きいほど、キーの角度のそばでキーのポーズそのものに寄ります
コマ打ち fps補正の更新をこの回数 / 秒に間引きます（0 = 毎フレーム）
誇張（0〜1）誇張用シェイプ（FC_…_Ex）の強さ。1 = 作った通り、0 = 誇張なし
パース補正の強さ（0〜1）広角で寄ったときの補正の強さ。0 = 補正なし、1 = 作った通り。Runner の「状態」に、今の距離（または画角）が出ます。軸が画角のキャラクターは、視点にカメラが無いと補正が掛かりません（インスペクターのプレビューの仮の視点など）
書き込む LOD の上限0 = すべての LOD に書く（初期値）。1 以上 = その LOD まで書き、それより粗い LOD には書きません（軽量化）。LODGroup に入っていないメッシュには常に書きます
補間双線形（標準）/ なめらか（Catmull-Rom）。Maya のセットアップタブの「補間」と同じ
Toon の顔の角度連動へ渡すマテリアル出力がオンのとき、Toon シェーダー用の値（_ToonFacialAngles）も書きます（初期値オン）

Unity でできないこと

  • ポーズの編集・格子の変更・ベイクは、Maya で行います。直したら出力し直してください
  • Unity が使う FBX は、必ず Maya でベイクして出力したものにしてください（頂点の並びが合うため）
