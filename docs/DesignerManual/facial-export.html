出力と Unity

最終更新日: 2026-10-03

Maya で作った補正を Unity に渡し、ゲームの中で動かすまでの手順です。

確認中: Unity 側の部品は動作テストを通っていますが、Maya が出力した実際のファイルを Unity に置いての通し確認は、まだ終わっていません。うまくいかないときは困ったときを見て、状況を開発者に伝えてください。

出力タブ（Maya）

項目内容
Unity 向けに出力FBX と補正データ（.fcpose）を書き出します。別のプロセスで書くので、Maya の画面は止まりません（「書き出し中… ○ 秒」と出ます）。中止・フォルダを開くもあります。開いているシーンは変わりません
UE 版向けに出力…補正データを .fcpose.json のまま書き出します（Unreal Engine 版の FacialController 用）
Timeline 用に出力（.fctrack）プレビューの強さ・感情・手動角度に打ったキーを、ショットごとのファイル（<ショット名>__<モデル名>.fctrack）にします。Unity 側の取り込みは 準備中（先に書き出しておけます）

出力の前に自動で検証が走り、エラー・未ベイク・ベイク後の変更があれば、それでも出力する / やめるを聞かれます。出力前に検証タブで直しておくのがおすすめです。

出力されるファイル

プロジェクトフォルダの facial\<キャラクター>\export\unity\ に、次の 2 つができます。

ファイル内容
<キャラクター>.fbx顔のメッシュと同じ骨格のモデル。ブレンドシェイプに、焼いた FC_ のシェイプが入ります（彫り用の fcs_ のシェイプと作業用のノードは入りません）
<キャラクター>.fcpose補正データ（格子・ポーズ・感情レイヤー・方針）

結果の欄に、メッシュの数・FBX に入った FC_ の数・除いた fcs_ の数・警告が出ます。

Unity での使い方

  1. 2 つのファイルを Unity のプロジェクトに置く（Assets の中）。.fcpose を置くと、補正のデータ（FacialCorrectionData）が自動でできます。FBX の Blend Shape Normals は Import にしてください（検証で確認できます）
  2. キャラクターの Prefab（またはシーンのオブジェクト）に Facial Correction Runner を付けます（Add Component › T-Drive › Facial Correction Runner）
  3. Runner の データの欄に、できたデータを入れます。対象のメッシュと基準ボーンは、空なら名前から自動で探します
  4. 再生すると、ゲーム中のカメラ（既定はメインカメラ）の角度に合わせて補正が掛かります。再生しなくても、Runner のプレビューで確認できます

Runner のインスペクター

欄内容
プレビュー再生しなくても、Scene ビューのカメラの角度で補正を掛けて確認します。プレビュー: オン / オフ、補正あり / 補正なし（比べる）、視点（Scene ビューのカメラ / ターンテーブル / 角度を指定）、格子ビューアを開く。オフにする・保存する・再生に入ると元の値に戻り、シーンは変更されません
データと対象データ・調整用アセット・対象メッシュ・基準ボーンなどの設定
状態見つかったシェイプの数・足りないシェイプ・今の Yaw / Pitch・倍率（表情 × 距離 × 強さ）・今の重み。足りないシェイプがあるときは、Maya で出力し直します
調整（簡単なパラメータ）下の「調整できる値」。調整用アセットがあれば、値を上書きして保存できます
感情の重み感情レイヤーごとの重み（0〜1）とミュート（オンで 0 として扱う）
視点補正の角度を決める視点（空ならメインカメラ）。手動の角度を使うをオンにすると、Yaw / Pitch を直接指定できます
マテリアル出力（任意）マテリアルへ角度・感情の重みを渡します。使わなければそのままで構いません
検証エラー / 警告 / 情報の件数と内容。シェイプの過不足・基準ボーン・取り込み設定などを確認します。「もう一度検証する」で取り直し
ボタンFC_* を 0 に戻す / キャッシュを作り直す（メッシュやボーンを変えたとき）/ Maya へ戻す JSON を書き出す…

調整用アセット

Runner の「調整」で調整用アセットを作る…を押して保存場所を決めると、値を変えて保存できます。取り込んだデータは変わらず、.fcpose を取り込み直しても調整は残ります。「上書き」にチェックを入れた行だけが使われます。Ctrl+Z で戻せます。

グリッドのウィンドウ

メニュー T-Drive › Facial › グリッド で開きます。Runner（またはデータ）を選ぶと、Maya のグリッドタブと同じ向き（上がふかん・左が −Yaw）で格子を表示します。緑 = キー / 水色 = 自動生成 / 灰 = 無し / 赤い枠 = メッシュに FC_ のシェイプが無い / 赤い点 = 今の角度。点をクリックすると、Scene ビューのカメラがその角度へ動き、プレビューが始まります。「固定」で表示対象を固定、「プレビュー」でオン / オフ、レイヤーも切り替えられます。

Maya へ戻す JSON

Unity で調整した値を Maya に持ち帰りたいときは、Maya へ戻す JSON を書き出す…を使います。強さ・追従などの値が JSON に出ます（端のフェードは入りません。Maya のセットアップタブで変えてください）。

調整できる値

項目意味
全体の強さ補正全体の強さ（0〜1）。0 で補正なし
追従の速さ重みが目標へ追いつく速さ。大きいほど速い。0 以下 = 即時
スナップの角度（度）視点がこの角度より大きく飛んだら、カット切り替えとみなして即時に反映します
距離フェード 開始 / 終了（m）視点が遠くなると補正が弱まり始める距離 / 補正が 0 になる距離。開始 = 終了 = 0 で無効
表情での弱め具合表情が強いとき補正を弱める度合い（0〜1）。0 = 弱めない
端のフェード（度）格子の範囲の外側で、補正が 0 へ消えていく幅
シャープさ 準備中キー角度の近くでキーのポーズそのものに寄せる度合い。欄はありますが、まだ効きません
コマ打ち fps 準備中補正の更新を間引く fps。欄はありますが、まだ効きません

Unity でできないこと

  • ポーズの編集・格子の変更・ベイクは、Maya で行います。直したら出力し直してください
  • Unity が使う FBX は、必ず Maya でベイクして出力したものにしてください（頂点の並びが合うため）
