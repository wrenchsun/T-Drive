ブレンドタブ

最終更新日: 2026-10-23

クリップからクリップへの切り替わり方を、ゲーム（Unity）と同じ秒数・同じ混ぜ方で、Maya のビューポートで確かめます。DirectX 11 は要りません。

  • ブレンド — 2 つのクリップを、決まった秒数でなめらかにつなぐこと。Unity の「固定秒のクロスフェード」と同じく、時間に比例して直線的に混ぜます
  • 遷移 — 待機 → 走り のように、状態が切り替わること
合成中は、ジョイントが合成につながっています。元のアニメーションのカーブは壊していませんが、合成したままシーンを保存しても、保存の間だけ元のつながりに戻して書くので、保存されたシーンのジョイントは元のままです（保存したあとは合成につなぎ直します）。ただし、合成中はジョイントにキーを打たないでください（オートキーは自動で切れます）。合成中に自分で足したつながりは、外すときに上書きせず残して知らせます。確認が終わったら「合成を外す」を押してください（画面にオレンジ色の注意が出ている間は合成中です。ウィンドウを閉じても外れます）。
合成の作成・「外す」は Maya の Ctrl+Z の対象外です（Ctrl+Z で半端に戻らないように）。戻すのは「合成を外す」だけです。

合成中は、リグのコントローラ（mGear の rig_controllers_grp、無ければ名前が _ctl で終わるもの）が非表示になります（合成はジョイントを直接動かすので、コントローラは元のキーのポーズのままで、メッシュと合わなくなるためです）。「合成を外す」で元の表示に戻ります。隠したくないときは、再生の行の「コントローラを隠す」を外してから合成を作ります（ショットの合成は常に隠します）。

合成中は、バナーの下に「今のブレンド: Idle 70% / Run 30%（f=35）」のように、タイムスライダーの今の位置のクリップの割合が出ます。スライダーを動かすと変わります（上半身レイヤーは含みません）。同じ文字がビューポートの左下付近（HUD）にも出るので、再生中でも見えます。合成を外すと消えます。

mGear などのリグ（ジョイントの移動・回転・スケールがまとめて別のノードからつながっているもの）でも合成できます。「合成を外す」で、そのまとめたつながりのまま元に戻ります。

入口 1: 遷移列を手で並べる

表に行を足して、上から順に再生する流れを作ります。例: 待機 1 秒 → 走り 1.5 秒 → ジャンプ。

列意味範囲・既定
クリップその行で再生するクリップ（クリップタブで作ったもの）
保持（秒）その行を見せる秒数。ループするクリップを指定の秒数だけ見せたいときに使います0 以上。既定 0（=切替位置で決める）
クロスフェード（秒）この行へ切り替わるときの混ぜる秒数。1 行目は使いません0 以上。既定 0.1
切替位置この行へ切り替えるのは、前の行のクリップがここ（0〜1）に達したとき（0.5 = 前のクリップの半分、1 以上 = 最後まで見せてから）。D-Drive の「切替位置」と同じ持ち主です。前の行の「保持」が 0 より大きいときは保持が優先。1 行目では使いません既定 1
速度再生の速さ（2 = 2 倍）0 より大きい。既定 1
  • 「＋ 行を足す」「－ 行を消す」「↑」「↓」で並べ替えます。行を右クリックすると、コピー・貼り付けができます（別のキャラクターの列を持ち込めます）
  • 最初に出る列は「Idle → Run → Jump」です。手で直すまでは、クリップを足したり消したりすると列も追いかけて作り直されます。直したあとで最初の列に戻したいときは「既定の列に戻す」を押します（今の列は消えます）
  • クロスフェードを 0 にすると、混ぜずに一瞬で切り替わります
  • 「この列で合成を作る」を押すと、スケルトンのアニメーションが列の通りに合成されます。再生範囲も合成の長さになります。▶ 再生で確認します

入口 2: 状態図をパラメータで動かす

MS2026 のプレイヤー（AC_PlayerPreview）と同じ、Idle / Run / Jump の 3 つの状態の切り替えを、ゲームと同じ条件・同じ秒数で試せます。

  1. クリップの名前から Idle / Run / Jump のクリップを探して割り当てた状態図（Run は _F を優先）を使います。スライダーを動かすか「状態図で合成を作る」を押すと、自動で使われます。結果は animset に入ります（「保存」かシーンの保存で書かれます）。作り直したいときは小さな「状態図を既定に戻す」を押します
  2. 「状態図で合成を作る」を押し、▶ 再生する
  3. 再生しながらSpeed（0〜1）やActionStateを動かす — その時刻から遷移します
  4. スライダーはドラッグを離したときに記録されます（ドラッグ中は記録しません）。記録はタイムラインに出ます: 横軸は合成の「長さ」（既定は記録の最後 + 2 秒）、赤い線がタイムスライダーの今のフレーム、上段に ActionState（色付きの大きなマーカーと「Jump(2)」）、下段に Speed（小さなマーカーと値）、一番下の帯が評価してできた状態（Idle / Run / Jump）の区間です。下の表（時刻 / パラメータ / 値 / その結果の状態）と、評価した遷移列の一行表示（例: 0.00s Idle → 1.23s Run（0.08s）→ …）も出ます
  5. タイムラインの操作: マーカーをクリックで選択（表と連動）、ドラッグで時刻を移動（フレームにスナップ）、Delete キーか右クリックで削除、段をダブルクリック（または「現在フレームに追加」）でそのフレームに今の値を追加します。記録はシーンに保存され、開き直すと戻ります（animset には入りません）
  6. タイムラインの横軸にはフレーム番号が出ます（マーカーのラベルは「Jump(2) f=90」、表の時刻は「f=90（3.00s）」、赤い線の横に今のフレーム）。マーカーの無い所をクリック / ドラッグすると、Maya の現在時刻がそのフレームへ動きます（スクラブ）。Speed は、スライダーの右の数値欄（0.00〜1.00。Enter で記録）でも入れられます
  7. まとめて作成: 「変更のたびに作り直す」は既定でオフです。オフのあいだは記録するだけで、上に「作り直していません」と出ます。まとめて打ってから「作り直す」を押すと、1 回だけ合成を作ります。オンにすると、記録を変えるたびに作り直します
  8. 「この列で合成を作る」で作った合成のままスライダーを動かしても反映されません（そのときは「状態図で合成を作る」を押すよう上に出ます）
パラメータ動き
Speed0.1 を境に Idle ⇄ Run（0.1 より大きい → Run へ、0.08 秒でクロスフェード。0.1 より小さい → Idle へ）。この状態図では速さの違いは出ません（速さのブレンドは下の「入口 3: Blend Tree パラメータ」）
ActionStateJump (2) にすると、Idle・Run から Jump へ（Fall (3) も Jump 扱い）。Jump 以外に戻すと、Speed に応じて Idle か Run へ（MS2026 の Controller と同じ）
  • 遷移はゲームと同じく「条件が成り立った瞬間」に始まります（クリップの終わりを待ちません）。遷移の最中は次の遷移を始めません
  • 動かしたパラメータは時刻つきで記録され、動かすたびに合成を作り直します（作り直しの間、再生の位置は保たれます）。「パラメータを最初から」で記録を消します
  • 長さの欄で、合成する秒数を決めます（既定 8 秒）
0.08 秒は状態図の遷移の値です。クリップごとの既定のクロスフェードは 0.1 秒（D-Drive）で、どちらに揃えるかは確認が必要です（仮の決め）。

入口 3: Blend Tree パラメータ（1D / 2D パッド）

Unity の Blend Tree と同じ式で、パラメータ（Speed や MoveX / MoveY）を動かしたときの混ざり方を確かめます。D-Drive の AnimEditor「確認する › ブレンド」の 3 つ目の手段にあたります。

D-Drive の AnimEditor「確認する › ブレンド」T-Drive のブレンドタブ
遷移シーケンス（クリップを順に、固定秒でクロスフェード）入口 1「遷移列」
レイヤー同時再生（上半身だけ別のクリップ）「レイヤー」（UpperBody）
Blend Tree パラメータ（float を 2D パッド / スライダーで動かす）この節「Blend Tree パラメータ」（3 つとも揃いました）
  1. まずブレンドツリーを用意します。「2D の移動ツリーを作る」は、Walk（無ければ Run）の _F / _B / _L / _R が 2 方向以上そろっているとき、Idle を中央にした 2D のツリー（パラメータ MoveX / MoveY）を作ります。「1D の Locomotion を作る」は、Idle(0) / Walk_F(0.5) / Run_F(1) のツリー（パラメータ Speed。Idle と Run があれば作れます）を作ります。できたツリーは状態図に入り、animset に保存されます（Undo もできます）
  2. 「ブレンドツリー」のプルダウンでツリーを選びます。X / Y のパラメータは状態図の float から選び直せます（1D は X だけ）
  3. 2D パッド（160 px）をドラッグして離すと、その位置のパラメータ値で合成が作り直されます。青い点が各モーションの位置（大きさが今の重み）、橙の十字が今の値です。右の「0 〜 1 / -1 〜 1」で範囲を切り替え、その下のスライダーでも動かせます（1D はこちら）。モーションごとの重みが % で名前の横に出ます
  4. ドラッグ中は作り直さず（重みの % とパッドの点だけ追従）、マウスボタンを離したときに 1 回だけ作ります（キー・ホイール・数値入力はその場で 1 回）。再生中に動かしても効き、時刻と再生状態は保たれます。「合成を作り直す」で手動でも作れます

ツリーを自分で作る・直す

  • モーションの表 — パッドの下に、ツリーのモーションが一覧で出ます。クリップはプルダウンで選び、しきい値（1D）か位置 X / Y（2D）は数値で入れます（Enter かフォーカスを外すと保存）。行の「削除」で消せます（最後の 1 つは消せません）
  • ＋ モーションを足す — 未使用のクリップを、空いているしきい値 / 位置（2D は (0,1) (0,-1) (-1,0) (1,0) … の順）で足します。あとで表で直します
  • ツリーを新規… — 名前・種類（1D / 2DSimpleDirectional / 2DFreeformDirectional / 2DFreeformCartesian）・パラメータ名を決めて作ります（最初のモーションはクリップ 1 つ目。新しいパラメータ名は状態図に float として足されます）。ツリーを削除は確認のあと状態図から消します
  • パッドの青い点を Ctrl を押しながらドラッグすると、そのモーションの位置を動かせます（表と連動。ふつうのドラッグはパラメータの値を動かします）
  • しきい値や位置が他のモーションと重なると、保存はされますが警告が出ます（重みが決まらないため。値を変えてください）。変更はすべて animset の変更なので、Ctrl+Z で 1 操作ずつ戻せます
種類重みの決め方（Unity と同じ）
1D隣り合う 2 つのしきい値の間で線形。範囲の外は端のモーションだけ
2D Simple Directionalパッドの角度で隣の 2 モーション + 中央（原点）の Idle を混ぜる。外側（大きさ 1 以上）では中央は 0
2D Freeform Directional / CartesianUnity の gradient band interpolation。角度と大きさ（Directional）か位置（Cartesian）の差で決める
  • 長さの違うクリップは、Unity と同じく正規化時間で同期します（どのクリップも同じ割合の位置を読み、全体の長さは重み付き平均）。回転は四元数で混ぜます
  • 合成中の「今のブレンド」には、時刻によらず一定の割合（例: Walk_F 70% / Idle 30%）が出ます。UpperBody レイヤーはブレンドツリーには重ねません
  • 「合成を外す」で、元のカーブ・再生範囲に戻ります（遷移列の合成と同じ）。Cycle Offset と Mirror は未対応です
  • ツリーの JSON は animset の stateGraph.states[].blendTree にあります（Unity 側が読めば Blend Tree を作れる形です）。手で書くこともできます
  • 画面の写真は実機で撮ったものを足します（準備中）

レイヤー（上半身だけ別のクリップ）

「UpperBody を使う」にチェックを入れてクリップを選ぶと、胸から上と腕（既定では spine_C0_3_jnt 以下）にだけそのクリップが重なり、下半身は元の列のままです。重みのスライダー（0〜1）は、合成中でも動かせます。

再生

  • ▶ 再生 / ■ 停止、ループの切り替え、再生の速さ（1× / 0.5× / 0.25×）
  • 「合成を外す」— 元のカーブ・再生範囲・現在の時刻・ループ設定に戻します。外したあとの再生範囲は、合成する前と同じです
  • 「この列をショットへ」— ショットタブで開いているショットの、選んだキャラクターのクリップ列にします（先にショットとキャラクターを用意しておきます）

仕組み（知っておくと安心なこと）

  • 合成を作るときは、クリップの範囲をフレームごとに読み取るため、リグが重いと数秒かかります（MisotenChara の 113 フレームで 1〜2 秒ほど。メッセージに「読み取り / 切り離し / ノード作成」の所要秒が出ます。状態図のスライダーを動かしたあとの作り直しは、アニメーションが同じなら読み取りを省いて約 1 秒）。待っているあいだは進捗バーが出て、「中止」を押すと合成を作らずに元のままになります
  • Maya 標準の「タイム エディタ」ではなく、ジョイントのアニメーションを 1 フレームずつ読み取って、時間をずらした複製のカーブを作り、それを混ぜるノードでつなぐ方式です。どのレンダラー（OpenGL を含む）でも、同じに動きます
  • 混ぜるとき、回転は四元数で補間します（Unity と同じ）
  • 1 フレームごとの読み取りなので、元のカーブがなめらかな曲線のとき、合成の値は元の値とごくわずかに（0.1% ほど）ずれます
  • 遷移列の表は、いまは保存されません（Maya を閉じると消えます）。状態図とそのクリップの割り当ては animset に入ります（変えると「*」（未保存）になり、「保存」かシーンの保存で書かれます）
タイムスライダーに「遷移の区間」を色で示す機能はありません（作っていません）。遷移は、この画面の表と、▶ 再生で確かめてください。
