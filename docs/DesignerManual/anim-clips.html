クリップタブ

最終更新日: 2026-10-23

クリップは、シーンの中の「動きの範囲」（開始フレーム〜終了フレーム）に名前を付けたものです。Unity では 1 つのアニメーション（A_<ModelId>_<動作>.fbx）になります。1 本の長いアニメーションを、待機・走り・ジャンプのように切り分けて並べるイメージです。

クリップを作る

  1. Maya のタイムスライダーで、再生範囲をその動きの範囲に合わせます（上の「範囲 〜」に今の範囲が出ます。タイムスライダーを動かすと約 0.5 秒で追従します。カッコの中はルート以下のキーがある範囲）
  2. 「現在の範囲から追加」の動作を選ぶか入力します（Idle / Run / Jump など）。必要なら方向（F 前・B 後・L 左・R 右）と連番も
  3. 追加を押す — 名前は A_<ModelId>_<動作> の形で自動で決まります（例: A_MisotenChara_Run_F）
  • 同じ名前のクリップがあると「同じ名前のクリップがあります」と出て、追加されません。連番を変えてください
  • 範囲が重なっていても構いません（同じキーから速度違いのクリップを作るなど）
  • Idle / Walk / Run は最初からループ ON、それ以外はループ OFF です。あとから変えられます

クリップの属性

一覧で選ぶと、下の「選んだクリップ」で次を変えられます。

イベント

アニメーションの途中で「ここで足音を鳴らす」のような合図を付けます。タイムスライダーを動かして、付けたいフレームに合わせてから押します。

  • 現在フレームに追加 — 欄に書いたキー（例: Hit）のイベントを足します
  • 足音 左 / 右 — OnFootPlant を足します。引数は左 = 0、右 = 1 です 仮の決め
  • クリップの範囲の外のフレームには付けられません。右クリックで削除、またそのフレームへの移動ができます

サムネイル

右クリックの「サムネイルを作る」で、クリップの先頭フレームの小さな画像を作ります（今のビューポートのカメラで撮ります）。ビューポートが無い環境（バッチ実行など）では作れません。その場合は理由が出るだけです。。キーを直しただけでは古い画像のままです（名前と範囲が変わったときだけ自動で撮り直します）。右クリックの「サムネイルを作り直す」で撮り直せます

保存と自動の読み込み

クリップは anim/<ModelId>/animset.json に保存されます（上の「保存」、またはシーンを保存したときに自動で）。シーンを開き直すと自動で読み込まれます。
