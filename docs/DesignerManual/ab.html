A/B 比較

最終更新日: 2026-09-28

「今の見た目（A）」と「試したい案（B）」を同じカメラ・同じライト・同じ解像度で見比べて、良い方を採用します。

はじめの一歩

  1. A/B タブの バリアント追加… で案を作る（例: 名前 B、説明「顔の影を弱く」、複製元 base）。作った案は自動で B に入ります
  2. ルックタブの 編集先 を B にして値を変える（変えた項目は黄色の太字になります）
  3. A/B タブで 切替（Alt+T） を押して、ビューポートで見比べる
  4. 並べてキャプチャ で画像を並べて比べる。正面 / 3/4 / 横 / 後ろ を一括 にチェックすると 4 方向ぶん撮れます
  5. B が良ければ B を採用（B の内容が base になります）。ヘッダーの 保存 を忘れずに

画面の説明

項目内容
A / B比べる 2 つの案。base（基本の値）か、作ったバリアントを選びます
A を表示 / B を表示 / 切替（Alt+T）ビューポートの表示を切り替えます。Alt+T はビューポートにカーソルがあっても効きます
並べてキャプチャA と B を同じ条件で撮影します（1920×1080）。「顔 / 全身」で写す範囲を選べます
比較: 左右 / ワイプ左右に並べるか、1 枚の画像をスライダーで A と B に分けて見るか
差分の表A と B で値が違う項目の一覧。行をダブルクリックするとルックタブでそのマテリアルが開きます
B を採用B の内容を base に確定して B を消します。ルックタブの 元に戻す で取り消せます
B を削除B を消します（元に戻す で取り消せます）
キャプチャ画像は captures/<キャラクター>/ に日時・環境・角度付きの名前で保存されます（Git には入りません）。採用した理由と画像は、ルックを確定するときにルックの履歴（looks/<キャラクター>/CHANGELOG.md）に残す運用です。
撮影のときは一時的にジョイントやグリッドを隠します。撮影が終わるとビューポートの表示設定は元に戻ります。
