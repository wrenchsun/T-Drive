プレビュー設定

最終更新日: 2026-09-28

「プレビュー」タブでは、ゲームと同じ条件（環境プロファイル）で、決まったカメラ・ライトから見られます。

環境

ゲームのどの画面の条件で見るかを選びます（今は ms2026_ingame = ゲーム中の画面）。明るさの圧縮（トーンマップ）・カメラの画角・キャラクターライトがその画面と同じになります。

カメラ

操作内容
範囲: 顔 / 全身顔のアップか、全身が入る距離か
正面 / 3/4 / 横 / 後ろ / 3/4 左その向きから見るカメラ（tdPreviewCam）に切り替えます。画角はゲームのカメラと同じです
カメラを切り替えたあとも、普段どおり Alt + ドラッグで自由に動かせます。

キャラクターライト

操作内容
正面上 / 右前上 / 左前上 / 真上 / 逆光よく使う向き（右・左は画面から見た向き）
ゲームと同じ環境プロファイル（ゲーム）のライトの向きに戻します
ヨー（水平）/ ピッチ（高さ）向きを細かく変えます。値は Unity のライトの回転（X = ピッチ、Y = ヨー）と同じです
ライト回転 ▶ライトをぐるぐる回します。影の境界がチラつかないか・変な所に影が出ないかを確かめるのに使います。もう一度押すと止まります
Unity の影の安定化を掛けるゲームと同じように、ライトが動いたとき影を少し遅れて・小さな揺れは無視して追従させます。効き具合は キャラクタータブ の「平滑化」「ヒステリシス」。機能タブで「ライトの安定化」がオンのときだけ選べます
小さく揺らす（±2°）ライトを細かく揺らします。安定化を掛けると影の境界がチラつかなくなることを確認できます（ヒステリシスを揺れ幅より大きくする）
ゲーム中のライトはキャラクターの後ろ上から当たっています（InGame の設定）。正面から見ると顔がほぼ影側になるので、顔の調整は「正面上」などで確認し、最後に「ゲームと同じ」で見え方を確かめてください。

Unity とのパリティ

Maya 側の設定がゲームと同じ見た目になる状態かを一覧します。「要確認」があれば直してください。色の設定は 色の設定を Unity に合わせる で直ります。表示方式（DirectX 11）は はじめに を参照。

この条件を保存

環境とライトの向きを looks/<キャラクター>/preview.json に保存します。次に Look を開いたとき同じ条件に戻るので、A/B 比較の条件をそろえるのに使えます。
