# 05. Maya ツール仕様（T-Drive Toon エディタ）

## 1. 導入と起動

| 項目 | 仕様 |
|---|---|
| 配布形態 | Maya モジュール（`tools/install_maya_module.ps1` が `Documents/maya/modules/TDriveToon.mod` を生成し、リポジトリの `maya/` を指す） |
| 起動時処理 | `userSetup.py`: メインメニュー「T-Drive Toon」追加、MCP 用 commandPort `:7001` を開く（`TDRIVE_MCP_PORT=0` で無効） |
| エディタ | メニュー「T-Drive Toon > エディタ」。ドッキング可能な 1 ウィンドウ、タブ 4 つ（部位 / ルック / A/B / プレビュー） |
| 前提 | VP2 レンダリングエンジン = **DirectX 11**、カラーマネジメント ON・ビュー変換 = Un-tone-mapped (sRGB)。違う場合は起動時に警告し、ビュー変換はワンクリックで合わせる（[09](09_render_parity.md) §2） |

## 2. 画面構成

```
┌ T-Drive Toon ─────────────────────────────────────────────┐
│ Look: looks/unitychan/look.json  v0.1.0  ●未保存           │
│ [新規] [開く] [保存] [別名保存]   表示: (●Toon ○元の見た目) │
├──────┬──────┬──────┬────────────────────────────────────────┤
│ 部位 │ ルック │ A/B │ プレビュー │                          │
└──────┴──────┴──────┴────────────────────────────────────────┘
```

- ヘッダーは常時表示。**Toon ⇔ 元の見た目** の切替はワンクリック（R-4）
- 未保存の変更がある状態でシーンを閉じる・Look を開き直すときは確認ダイアログ

## 3. 部位タブ（R-1: モデルセットアップ）

```
┌ 部位 ────────────────────────────────────────────────────┐
│ [自動登録]  [選択から登録…]  [部位を選択]  [登録解除]      │
│ ┌───────────────┬──────────┬─────────┬────────────────┐ │
│ │ マテリアル     │ 部位      │ ロール   │ メッシュ        │ │
│ │ face          │ face      │ 顔 ▼    │ mesh_root/face │ │
│ │ hair          │ hair      │ 髪 ▼    │ hair_front …   │ │
│ │ eye_L1        │ eye       │ 目 ▼    │ eye_L_old      │ │
│ │ Left          │ (未登録)   │ —       │ …              │ │
│ └───────────────┴──────────┴─────────┴────────────────┘ │
│ マスク: [Toon マスク初期化] [スムーズ法線を焼く] [塗る: R G B A] │
└──────────────────────────────────────────────────────────┘
```

| 操作 | 仕様 |
|---|---|
| 自動登録 | シーン内の全マテリアルをロール推定ルール（[02](02_look_definition_spec.md) §5）で登録。**未登録のものだけ**が対象（上書きオプションあり） |
| 選択から登録 | 選択中のメッシュ / 面のマテリアルを、入力した部位名・選んだロールで登録。既に他部位に属するマテリアルは移動 |
| ロール変更 | 表のコンボボックスで変更。プリセットを再適用するか確認する |
| 部位を選択 | 部位に属するメッシュを Maya で選択（どこが何の部位かを目で確認） |
| Toon マスク初期化 | 対象メッシュに Color Set `tdToonMask` を作り白で埋める（既存なら何もしない） |
| スムーズ法線を焼く | UV Set `tdSmoothNormal` に接空間スムーズ法線を書く（[03](03_shader_spec.md) §5） |
| 塗る | Paint Vertex Color Tool を `tdToonMask` の指定チャンネル・黒で起動。**ビューポートは塗った瞬間に Toon 表示へ反映**。チャンネル単体表示モード（R だけを白黒表示等）を持つ |

**目標: UnityChan の FBX を読み込んでから、全部位が登録されて Toon 表示になるまで 3 クリック以内。**

### 3.1 顔の法線（Toon Normal、T-10）

顔の影を「作画的な 2〜3 パターン」に収めるため、顔メッシュの法線を単純な形（楕円体）の法線に寄せる。

| 操作 | 仕様 |
|---|---|
| プロキシ作成 | 対象（部位 or 選択メッシュ）のバウンディングボックスに合わせた楕円体 `tdFaceNormalProxy` を作る（ワイヤー表示）。移動・回転・スケールで形を合わせる |
| 転写 | 各頂点の法線を `normalize(lerp(元の法線, 楕円体の法線, 強さ))` にする。頂点を選択していればその頂点だけ |
| リセット | 法線のロックを外して元の法線に戻す |

- 楕円体の法線は解析的に求める（プロキシの逆行列で単位球へ写し、逆転置で戻す）
- 書き込み先は変形前（Orig）シェイプ（スムーズ法線と同じ理由）。ロックした法線は FBX に書き出され、Unity は法線を Import で読む（docs/08）
- 法線を変えたらスムーズ法線（アウトライン用）とは独立（スムーズ法線は位置から作るので影響しない）

### 3.2 カメラ角度の補正 BlendShape（T-20）

横顔・3/4 で顔の形を作画的に補正する（目を前に出す・鼻を短くする・輪郭を変える等）。

| 操作 | 仕様 |
|---|---|
| 補正シェイプを作る | 顔メッシュを選んで「正面 / 3/4 / 横」のボタン → メッシュを複製（`<メッシュ名>_vc_<角度>`、横にずらして置く）。アーティストがこれを彫る |
| 登録 | 彫ったシェイプを顔メッシュの BlendShape（`tdViewCorrection_<メッシュ名>`）のターゲットにし、名前を Look の `characterSettings.viewCorrection` に記録 |
| プレビュー | 「カメラに連動」で、現在のカメラとキャラクターの角度から自動でウェイトが混ざる（Maya の DG ノードで組むのでカメラを回すとそのまま追従）。「連動を外す」で解除 |

角度 → ウェイト（Unity の `ToonCharacter` も同じ式。`envmath.view_correction_weights`）:

```
θ = キャラクターの正面（+Z）と、頭からカメラへの向きの水平面上の角度（0°〜180°、左右対称）
正面 = 1 - smooth(θ / 45)            （0° で 1、45° で 0）
3/4  = θ ≤ 45: smooth(θ / 45) / θ > 45: 1 - smooth((θ - 45) / 45)   （45° で 1）
横   = θ ≥ 45: smooth(min(θ - 45, 45) / 45)                           （90° 以上で 1）
smooth(t) = t * t * (3 - 2 t)  （0〜1 に clamp）
```

- 3 つのウェイトの和は常に 1（0°〜90° の間で）。90° より後ろは横のまま
- 補正シェイプが登録されていない角度は、そのウェイトを使わない（他の 2 つで 1 になるように正規化はしない = 未登録ならその角度では補正なし）

### 3.3 SDF 顔影マップの生成（T-21）

1. アーティストが、顔の UV に合わせて「**右からライトがこの角度で当たるとき明るい範囲（白）**」の白黒マスクを角度ごとに描く
   - ファイル名に角度（度）を入れる: `face_shadow_000.png`, `face_shadow_030.png`, …, `face_shadow_180.png`（0° = 正面、180° = 真後ろ）
   - 角度が大きいほど明るい範囲が狭くなる（包含関係）こと
2. キャラクタータブ「顔影マップ（SDF）」の **マスクから生成…** でフォルダを選ぶ → 各マスクの境界の符号付き距離を角度方向に補間して 1 枚にする（`tools/sdf/face_shadow_sdf.py`、16bit PNG）
3. 生成したマップを顔マテリアルの `_ToonFaceShadowMap` に設定し、`_ToonFaceShadowWeight` を上げる
4. 顔の正面・右の向き（`characterSettings.faceShadow`）は、キャラクターが +Z を向く既定のままでよい

## 4. ルックタブ（R-2 / R-5: 部位別調整・即時反映）

```
┌ ルック ─────────────────────────────────────────────────┐
│ 編集先: [base ▼]  （A/B タブで選んだバリアントも選べる）    │
│ ┌ 部位 / マテリアル ┐ ┌ パラメータ ───────────────────────┐ │
│ │ ▼ face           │ │ ▶ 共通   Blend [Opaque▼] RQ [ 0 ] │ │
│ │     face         │ │ ▼ 影                             │ │
│ │     mouth        │ │   影色        [■]                 │ │
│ │ ▼ hair           │ │   影の境界    ──●──── 0.45  ↺     │ │
│ │     hair         │ │   境界ぼかし  ●────── 0.02  ↺     │ │
│ │ ▶ eye            │ │   影の強さ    ─●───── 0.35  ↺     │ │
│ └──────────────────┘ │ ▶ 固定色  ▶ 線  ▶ マスク          │ │
│                      └──────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

| 項目 | 仕様 |
|---|---|
| 対象 | 左ツリーで **部位** を選ぶとその部位の全マテリアルへ一括設定、**マテリアル** を選ぶと単体に設定 |
| 値が混在 | 部位内でマテリアルごとに値が違う場合は「—」表示。操作すると全マテリアルがその値に揃う |
| 反映 | スライダー操作中も連続でビューポートに反映（setAttr のみ。シェーダー再コンパイルなし）。目標: 1 操作 < 16ms |
| リセット（↺） | ロールのプリセット値（プリセットに無ければパラメータ契約の既定値）に戻す |
| 編集先 | base か任意のバリアント。バリアント編集中は **base と違う値を強調表示** し、「base に戻す（上書き解除）」ができる |
| グループ | パラメータ契約の group（共通 / 影 / 固定色 / 線 / マスク）で折りたたみ。表示名は日本語、ツールチップに Unity プロパティ名 |
| Undo | エディタ内の値変更は独自の Undo/Redo（Ctrl+Z/Y、エディタにフォーカス時）。Maya の Undo キューには積まない |

### 4.1 テクスチャの差し替え（4-9、2026-09-28 追加）

ルックタブの「テクスチャ」グループで、マテリアルのテクスチャを差し替える（Look に保存され、Unity に渡る）。

| 項目 | Look | 備考 |
|---|---|---|
| ベースマップ | `common.albedo` | ↺ は **元マテリアルのテクスチャ**に戻す（登録時に自動で入るもの） |
| 法線マップ・強さ | `common.normal` / `common.normalScale` | 機能「法線マップ」がオンのとき表示。Unity と同じ +Y 形式 |
| 発光マップ・発光色・強さ | `common.emission` / `common.emissionColor` / `common.emissionIntensity` | 機能「発光」がオンのとき表示 |
| Toon マスク・髪ハイライト・MatCap・顔影マップ | Specific（従来どおり） | 各グループ |

- パスはプロジェクトフォルダ基準（[13](13_distribution.md) §1）。ファイルが見つからないテクスチャは欄を赤くし、ツールチップに理由を出す
- **テクスチャを読み込み直す**（ルックタブ上部）: 外部のペイントツールで描き直したテクスチャを、全プレビューで読み込み直す

## 5. A/B タブ（R-3: 比較）

```
┌ A/B ────────────────────────────────────────────────────┐
│ A: [base ▼]   B: [B: 顔の影を弱く ▼]   [バリアント追加…] │
│ [A を表示] [B を表示] [切替 (Alt+T)]  表示中: B            │
│ [並べてキャプチャ]  カメラ: [正面][3/4][横][後ろ] 一括 □   │
│ ┌──────────────┬──────────────┐                          │
│ │      A       │      B       │  ← 同一カメラ・ライトの画像 │
│ │              │              │    ワイプ（スライダー）表示も可 │
│ └──────────────┴──────────────┘                          │
│ 差分: face _ToonShadowStrength  0.35 → 0.10               │
│ [B を採用（base に確定）] [B を削除]                       │
└──────────────────────────────────────────────────────────┘
```

| 操作 | 仕様 |
|---|---|
| バリアント追加 | 名前・説明を入力。複製元は base か既存バリアント |
| 切替 | A ⇔ B の表示をビューポートで即時切替（ホットキー Alt+T）。見比べの基本操作 |
| 並べてキャプチャ | 同一カメラ・ライト・解像度で A/B を撮り、左右 or ワイプで表示。「一括」ON でカメラプリセット 4 方向ぶん撮る。画像は `captures/<character>/<日時>_<A|B>_<variant>.png`（Git 管理外） |
| 差分 | `look.diff(A, B)` の一覧。行クリックで該当部位をルックタブで開く |
| 採用 | B の解決結果を base に確定し B を削除（取り消しはエディタ Undo） |

## 6. プレビュータブ（R-4）

| 項目 | 仕様 |
|---|---|
| 環境 | Unity 環境プロファイル（`looks/_env/*.json`）を選択。色空間・トーンマップ・メインライト・カメラ FOV/Near/Far が Unity と同じになる（[09](09_render_parity.md) §3） |
| カメラプリセット | 正面 / 3/4 / 横 / 後ろ / 3/4 左。対象は「顔」か「全身」。専用カメラ `tdPreviewCam` を作り、現在のモデルパネルに割り当てる。**画角は環境プロファイルの縦 FOV**（Unity の Gate Fit=Vertical と同じ） |
| ライト | キャラクターライトのヨー・ピッチのスライダー + プリセット（正面上 / 左上 / 右上 / 逆光 / 真上）。**ライト回転アニメ再生**（ヨーを自動回転し、影の境界の動き方を確認） |
| 影の安定化（T-17） | 機能 `lightStabilize` がオンのとき「Unity の影の安定化を掛ける」を選べる。キャラクタータブの平滑化・ヒステリシスで、表示するライト方向を Unity と同じ式（[08](08_unity_port_plan.md) §3.3）で追従させる。**小さく揺らす**（±2° のランダム）でヒステリシスの効果を確認できる。保存されるライトの向きは目標の値 |
| 接地影（T-29） | キャラクタータブの接地影を「使う」にすると、足元にプレビュー専用の板（`tdContactShadow`、属性 `tdPreviewOnly`）を置き、左右の足ジョイント（名前に Left/Right + Foot/Ankle）に追従する影を Unity と同じ式で描く。部位登録・FBX 出力の対象外。Toon 表示を切る・機能をオフにすると隠れる |
| 画面上の線（T-23） | キャラクタータブのインナーラインを「使う」にすると、プレビューのモデルパネルに Render Override `tdToonScreenLine` を割り当て、Unity と同じ判定式（[03](03_shader_spec.md) §10）で線を描く。使わないときは通常の VP2。ビューポートの MSAA は効かない（パリティキャプチャと同じ条件） |
| ライト色 | プレビュー用。Look には保存しない |
| パリティキャプチャ | 環境プロファイルの解像度（既定 1920×1080）・MSAA OFF で撮る。Unity 側キャプチャと `tools/parity/compare.py` で比較（[09](09_render_parity.md) §5） |
| 環境の保存 | カメラ・ライト設定は `looks/<character>/preview.json` に保存し、A/B 比較の条件を再現できるようにする |

## 7. 出力

| 操作 | 出力 | 用途 |
|---|---|---|
| Look 保存 | `looks/<character>/look.json` | 唯一の真実。Git 管理 |
| Unity 用出力 | `build/unity/<character>/<character>_<variant>.materialdata.json` | MS2026 インポーター入力（[02](02_look_definition_spec.md) §7） |
| FBX 出力 | `build/unity/<character>/<character>.fbx`（頂点カラー `tdToonMask`・UV `tdSmoothNormal`・接線を含む） | メッシュデータの移送 |

## 8. MCP / 自動化

- エディタの全操作は `tdrive_toon.session.current()` の API で UI 無しに実行できること（MCP・テスト用）
- `maya/mcp_scripts/` に定型スクリプト: `reload_tdrive.py`（リロード）、`setup_unitychan.py`（FBX 読込 → 自動登録 → Toon 表示）、`capture_ab.py`（A/B 4 方向キャプチャ）

## 9. 非機能要件

| 項目 | 目標 |
|---|---|
| 反映速度 | スライダー操作 → ビューポート反映 16ms 以内（UnityChan 規模） |
| Toon 表示切替 | 1 秒以内 |
| 安全性 | 元マテリアル・元の割り当てを破壊しない。Toon 表示のまま保存したシーンも「元の見た目」に戻せる |
| テスト | Maya 非依存層は pytest、Maya 依存層は mayapy のスモークテスト |
